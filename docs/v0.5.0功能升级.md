# v0.5.0 功能升级总结

## ✅ 已完成功能

### 1. 单文件 .csx 脚本热插拔 🔥
**核心改进**：用户现在可以直接将 `.csx` 文件放入 `Plugins/` 根目录，无需创建目录结构和 manifest.json

**实现细节**：
- 修改 `PluginScanner.ScanAsync()` 扫描根目录的 `.csx` 文件
- 新增 `TryLoadStandaloneScriptAsync()` 方法自动生成虚拟 manifest
- FileSystemWatcher 自动检测 `.csx` 文件变化并热重载
- 单文件脚本默认 ID 格式：`script-{文件名}`

**用户体验**：
```
之前：
1. 创建 Plugins/MyScript/ 目录
2. 写 manifest.json（20+ 行配置）
3. 写 script.csx
4. 等待自动加载

现在：
1. 写 quick-note.csx
2. 拖到 Plugins/ 目录
3. ✅ 立即可用！
```

### 2. 页面切换淡入淡出动画 ✨
**改进**：系统配置/插件管理/开发工具三个面板切换时增加平滑过渡

**实现细节**：
- 修改 `SwitchPanel()` 方法
- 旧面板先淡出（150ms） → 切换 Visibility → 新面板淡入（200ms）
- 使用 CubicEase 缓动曲线

**效果**：从生硬的瞬间切换变为优雅的淡入淡出

### 3. 插件卡片入场动画 🎬
**改进**：插件列表加载时，卡片逐个从下方滑入并淡入

**实现细节**：
- 修改 `RefreshPluginList()` 方法
- 每个卡片初始状态：`Opacity=0`, `TranslateY=20`
- 延迟执行动画：第 i 个卡片延迟 i*50ms
- 使用 `AnimationHelper.SlideDown()` 执行 400ms 的滑入+淡入动画

**效果**：列表加载时有视觉节奏感，而非全部突然出现

### 4. 拖放安装功能 📦
**新功能**：在插件管理面板添加拖放区域，支持拖入文件自动安装

**实现细节**：
- XAML 添加 `DropZone` Border 组件
- 支持 `.csx` 文件：自动复制到 Plugins/ 根目录
- 支持 `.lpak` 文件：调用 LpakInstaller 安装
- 拖入时高亮边框和背景
- Toast 提示安装结果

**用户体验**：
- 拖入 `.csx` → 即刻生效（热插拔）
- 拖入 `.lpak` → 自动解压安装
