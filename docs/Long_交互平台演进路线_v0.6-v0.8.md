# Long助手 交互平台演进路线（v0.6–v0.8）

> 决策日期：2026-07-18
> 参考对象：uTools 的统一入口、上下文匹配、超级面板和插件生态交互
> 产品原则：参考交互逻辑，不复制视觉，不兼容 uTools 插件

## 1. 已确认的产品边界

Long助手不会实现 uTools 插件兼容层，也不会复制其 API、Manifest、运行时或插件包格式。

- Long 已建立自己的命令协议、能力权限、WPF/Web 运行时和设计系统。
- 兼容层会长期受制于第三方私有行为，增加安全、维护和版本追踪成本。
- Long 的核心优势是 Windows 原生深度集成，不需要为了兼容牺牲架构边界。
- 第三方开发者应使用 Long SDK 和 Long UI Kit，获得稳定、可审计的本地能力。

视觉继续采用 Long 自有的优雅、华丽、扁平、动效化语言；uTools 只作为交互效率参考。

## 3. v0.6：上下文与搜索平台

### 3.1 统一上下文快照

新增只读 `ContextSnapshot`，一次呼出只采集一次，所有命令共享同一份快照：

```text
ContextSnapshot
├── Text / Url
├── ClipboardText / ClipboardImage
├── Files / Folders
├── ExplorerSelection
├── ForegroundWindow
└── Source + Timestamp + Sensitivity
```

设计要求：

- 每种来源由独立 `IContextProvider` 提供，失败不能阻塞命令中心。
- 图片、文件和敏感文本只在命令明确声明接收时传递。
- UI 必须展示当前检测到的上下文来源，并允许用户移除。
- 插件只能取得 Manifest 权限允许的数据。
- 上下文快照离开当前执行链后释放，不写入日志正文。

### 3.2 搜索提供者

新增 `ISearchProvider`，允许插件返回数据结果，而不只是静态功能指令：

```text
查询输入
  → 静态命令索引
  → 插件搜索提供者
  → 本地文件/设置提供者
  → 合并、去重、排序
  → 统一结果模型
```

统一结果必须支持：标题、副标题、图标、来源、主操作、次级操作、是否可固定和继续搜索令牌。

### 3.3 排序原则

排序分数由文本匹配质量、上下文类型、用户固定、最近使用、使用频率、插件优先级和来源健康度组成。动态偏好数据只保存在本机，并提供清除入口。

## 4. v0.7：Long 超级面板与插件生命周期

### 4.1 Long 超级面板

超级面板是命令中心的鼠标形态，共享同一个 `CommandRegistry`、`ContextSnapshot`、`CommandExecutor` 以及固定和最近使用数据。

- 可配置鼠标中键或长按右键呼出。
- 根据文本、图片、文件和文件夹自动筛选操作。
- 支持固定常用指令、拖拽排序和文件夹分组。
- 滚轮切换分组，Esc 关闭并归还原窗口焦点。
- 不默认加入语音输入，避免引入云服务依赖。

### 4.2 生命周期状态

```text
Loaded → Running → Background → Stopped
              ↘ Error
```

每个插件可声明退出后是否后台运行、是否跟随宿主启动、默认嵌入或分离窗口，以及是否允许向主搜索提供动态数据。

声明统一收敛在 Manifest 的 `lifecycle` 节点：`start_with_host`、`close_behavior`、`default_presentation` 与 `search_in_background`。旧插件省略该节点时使用安全兼容默认值；历史 `Disabled` 状态作为 `Stopped` 的兼容别名保留原二进制数值。

### 4.3 v0.7 验收

- [x] 超级面板与 Command Palette 的命令和排序完全一致。
- [x] 多数据源匹配不产生第二套插件配置。

## 5. v0.8：Long 插件市场

第一阶段市场只解决可信发现和分发，不建设会员、支付或社交系统。

### 5.1 必需能力

- 分类、搜索、详情、版本记录和权限展示。
- 一键安装、升级、降级和卸载。
- SHA-256、发布者签名和包结构校验。
- 安装前权限差异提示。
- 宿主、UI Kit 和 API 最低版本兼容检查。
- 本地安装源和远程 Registry 使用同一数据模型。

### 5.2 安全门槛

- 市场包不得绕过 Manifest 权限。
- 原生 DLL 插件标记为高信任类型，并显示更强提示。
- 安装和升级必须可回滚。
- Registry 元数据与实际包哈希必须匹配。
- 默认不自动静默升级原生插件。

### 5.3 v0.8 验收

- [x] 市场可浏览、搜索、安装、更新和卸载插件。
- [x] 权限与版本差异在确认前可见。
- [x] 损坏、篡改和不兼容包被拒绝。
- [x] 更新失败可恢复旧版本。
- [x] 市场不可用时不影响本地插件和命令中心。

## 6. 实施顺序

```text
ContextSnapshot
    ↓
Search Provider + Result Model
    ↓
固定 / 最近使用 / 动态排序
    ↓
二次搜索
    ↓
Long 超级面板
    ↓
完整插件生命周期
    ↓
Long 插件市场
```

不得先做超级面板视觉外壳，再反向补上下文和命令协议；不得在签名、权限和回滚策略完成前开放远程插件自动安装。
