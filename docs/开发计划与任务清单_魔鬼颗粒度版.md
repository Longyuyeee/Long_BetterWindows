# Long_BetterWindows 开发计划与任务清单 (魔鬼颗粒度版)

## 开发原则 (Guiding Principles)
1. **最小侵入：** 严禁全量替换，坚持增量更新。
2. **停顿确认：** 每步必测，每测必审。
3. **魔鬼颗粒度：** 逻辑拆分至不可再分。

---

## 第一阶段：宿主程序骨架与视觉底座 (Project Scaffolding)
本阶段目标：搭建一个具备 Mica 材质和基础窗口管理能力的 WPF 壳子。

- [ ] **1.1 项目初始化**
    - [ ] 创建基于 .NET 8/9 的 WPF 应用程序项目 `Long_BetterWindows.Host`。
    - [ ] 配置项目的全局引用（Global Usings）和基础命名空间。
    - [ ] 引入 `Wpf.Ui` 或类似的现代 UI 库。
- [ ] **1.2 现代窗口特性实现**
    - [ ] 实现 `WindowBackdrop` 辅助类，确保在 Win10/11 上正确开启 Mica 或 Acrylic 材质。
    - [ ] 移除原生标题栏，实现自定义圆角标题栏及基础控制按钮（最小化、关闭）。
- [ ] **1.3 基础日志与异常捕获**
    - [ ] 集成 Serilog 或类似日志组件，确保所有系统操作均可追踪。
    - [ ] 建立全局未处理异常捕获（AppDomain/Dispatcher），防止程序因插件错误直接崩溃。

---

## 第二阶段：虚拟桌面与布局引擎 (Desktop Simulation)
本阶段目标：实现类似桌面的图标排列与容器化交互。

- [ ] **2.1 桌面栅格系统 (IconGrid)**
    - [ ] 实现自定义 `WrapPanel` 或 `UniformGrid` 控件，支持图标自动对齐。
    - [ ] 编写图标拖拽位置交换的算法（基于坐标碰撞检测）。
- [ ] **2.2 图标卡片组件 (IconCard)**
    - [ ] 开发苹果风图标控件：包含毛玻璃背景、圆角图标、文字标签。
    - [ ] 实现鼠标悬停的高光和缩放动效（Storyboard）。
- [ ] **2.3 任务栏/Dock 栏基础**
    - [ ] 实现底部自动隐藏的 Dock 容器。
    - [ ] 定义“系统内置工具”（设置、中心）的特殊图标样式。

---

## 第三阶段：插件引擎核心 (Plugin Engine)
本阶段目标：让宿主具备识别、加载和管理外部逻辑的能力。

- [ ] **3.1 插件元数据契约 (Manifest Logic)**
    - [ ] 实现 `ManifestReader`：解析 JSON，校验版本及权限声明。
    - [ ] 定义插件状态机：`Loaded`, `Running`, `Error`, `Disabled`。
- [ ] **3.2 动态加载机制 (Plugin Loader)**
    - [ ] 基于 `AssemblyLoadContext` 实现插件隔离加载，确保插件 DLL 不锁定。
    - [ ] 实现接口发现机制：扫描实现 `ILongPlugin` 接口的类。
- [ ] **3.3 宿主-插件 IPC 代理**
    - [ ] 建立 `HostProvider` 单例：作为插件调用 API 的统一入口。
    - [ ] 实现异步任务分发逻辑，确保插件调用系统 API 时不阻塞 UI 线程。

---

## 第四阶段：核心原子能力开发 (Capability Services)
本阶段目标：逐一攻克 Windows 系统集成的难点接口。

- [ ] **4.1 系统热键服务 (HotKeyService)**
    - [ ] 封装 `RegisterHotKey` Win32 API。
    - [ ] 实现热键冲突检测逻辑，并提供友好的 UI 冲突提示。
- [ ] **4.2 资源管理器感知服务 (ShellSelectionService)**
    - [ ] 实现 `IShellWindows` COM 接口调用。
    - [ ] 编写算法换算选中文件的屏幕物理坐标。
- [ ] **4.3 NTFS ADS 存取服务 (ADSService)**
    - [ ] 封装 `CreateFile` 与 `GetFileInformationByHandleEx` 用于读写备用数据流。
- [ ] **4.4 注册表与外壳注入服务 (Registry/ShellService)**
    - [ ] 实现安全的注册表写入与自动备份/回滚逻辑。
    - [ ] 实现基于稀疏包（Sparse Package）的右键菜单注入逻辑。

---

## 第五阶段：首批工具开发 (The First Tools)
本阶段目标：真实落地“文件夹备注助手”。

- [ ] **5.1 【工具中心】开发**
    - [ ] 实现插件 ZIP 包的本地解压与安装界面。
- [ ] **5.2 【文件夹备注助手】逻辑实现**
    - [ ] 编写“一键开启备注列”的注册表脚本。
    - [ ] 实现基于快捷键触发的毛玻璃 HUD 输入框。
    - [ ] 集成 ADS 存储逻辑。

---

## 阶段性回顾准则 (Checkpoint Rules)
- 每次完成 [ ] 标记项后，必须输出该项的完整代码及测试结果。
- 严禁连续执行超过 3 个子项而不进行回顾。
- 每次文档变更后，需立即检查文件内容是否被错误截断。
