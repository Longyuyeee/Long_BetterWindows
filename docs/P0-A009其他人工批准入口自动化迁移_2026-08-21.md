# P0-A009 其他人工批准入口自动化迁移

## 目标

退役物理 DPI、辅助功能、真实下载和干净 Windows 的人工批准入口，使自动采集结果可以直接由哈希锁定的汇总器验证。真实物理环境仍是采集前提，但 reviewer、签字和 checklist 不再影响发布资格。

## 完成内容

- 删除 4 个 `approve-*-evidence.ps1` 脚本和旧下载人工审阅测试。
- DPI 原始证据/矩阵升级为 schema v3/v4，固定 4 档、32 份截图及元数据哈希。
- 辅助功能原始证据/矩阵升级为 schema v4/v5，固定 3 种真实 Windows 配置与 UIA 焦点/live-region 事件。
- 干净环境原始证据/汇总升级为 schema v2/v3，固定候选身份、25 插件、42 命令、命令和桌面 UI 冒烟哈希。
- 下载原始证据/汇总升级为 schema v2/v4，固定候选包、`ZoneId=3`、脱敏 HTTPS 来源和证据哈希。
- 更新现行执行文档，不再引用已删除批准脚本。
