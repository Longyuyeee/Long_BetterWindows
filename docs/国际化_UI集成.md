# Long窗口国际化 UI 集成

> 状态：G1、G2 前三批及工作流前三个子批次的代码已完成，整体国际化进行中
> 语言：`zh-CN`、`en-US`
> 最后更新：2026-07-24

## 目标与边界

国际化服务于 Long 自身的优雅、扁平、动效化 Windows 体验。语言切换不得改变插件权限、命令参数、工作流审查或市场信任语义，也不承担 uTools 插件兼容。

宿主负责自身界面和统一状态文案；Long 原生插件可在后续声明自己的语言资源。插件未声明翻译时必须如实显示原内容，不使用机器翻译伪造完整覆盖。

## G1 已完成

1. `I18nService` 从静态占位实现升级为实例服务，支持中文完整回退、英文覆盖、未知语言拒绝和资源键查询。
2. 当前语言保存到 `%LocalAppData%\LongBetterWindows\language.json`，使用同目录临时文件与原子移动，启动时恢复。
3. `--language zh-CN|en-US` 可为质量采集覆盖当前语言，不修改持久化选择。
4. 语言资源映射到 WPF `ResourceDictionary` 的 `i18n.*` 动态键；设置页切换后即时刷新已迁移控件、页标题与运行状态。
5. 已迁移主窗口标题栏、命令中心/超级面板入口、Tool Center 导航、页面标题、系统集成卡片、设置语言/主题/动效/隐私/鼠标手势。
6. 英文紧凑布局采用可换行侧栏文案与纵向手势卡操作，避免长英文挤压或裁切。
