## 📋 修复详情

### 1. WebView2 权限绕过 ✅

**修复方法**:
- 新增 `GetRequiredCapability()` 方法，映射 68 个 JS API 到对应的 capability
- 在 `DispatchJsCall()` 开头检查权限
- 设置 `PluginAccessContext` 以支持回滚追踪

**影响的 API**:
```javascript
// 以下 API 需要在 manifest.json 中声明对应的 capability
long.fs.ads.*          // 需要 "fs.ads.access"
long.registry.*        // 需要 "system.registry.write"
long.hotkey.*          // 需要 "system.hotkey"
long.http.*            // 需要 "network.http"
long.clipboard.*       // 需要 "system.clipboard"
long.screenshot.*      // 需要 "system.screenshot"
long.shell.getActive*  // 需要 "shell.selection"
long.shell.openUrl     // 需要 "shell.execute.url"
```

---

### 2. URL 协议注入 ✅

**修复方法**:
- 使用 `Uri.TryCreate` 验证 URL 格式
- 协议白名单：仅允许 `http`, `https`, `mailto`
- 拒绝 `file://`, `ms-settings:`, `shell:` 等危险协议

**阻止的攻击示例**:
```csharp
// ❌ 这些将被拒绝
long.shell.openUrl("file:///C:/Windows/System32/cmd.exe");
long.shell.openUrl("ms-settings:privacy-microphone");
```

---

### 3. C# 脚本沙盒缺失 ✅

**修复方法**:
- 移除危险命名空间导入：`System.IO`, `System.Diagnostics`, `System.Reflection`
- 实现 `RestrictedMetadataReferenceResolver` 类
- 程序集白名单：仅允许加载宿主和必要的运行时程序集

**影响**:
```csharp
// ❌ 脚本中不再可用
using System.IO;
File.ReadAllText("path");
Process.Start("cmd.exe");

// ✅ 必须使用宿主 API
await Host.FileOps.ReadFileAsync("path");
await Host.Process.StartAsync("cmd.exe");
```

---

### 4. HTTP SSRF 攻击 ✅

**修复方法**:
- 新增 `ValidateUrl()` 方法验证 URL 安全性
- 内网地址黑名单：`localhost`, `127.0.0.1`, `10.*`, `172.16-31.*`, `192.168.*`, `169.254.*`
- 响应大小限制：10MB

**阻止的攻击示例**:
```javascript
// ❌ 这些将被拒绝
await long.http.get("http://192.168.1.1/admin");
await long.http.get("http://localhost:6379/");
await long.http.get("http://169.254.169.254/metadata"); // AWS IMDS
```

---

### 5. 注册表路径遍历 ✅

**修复方法**:
- 检测 `..` 路径遍历
- 阻止绝对路径和 `HKEY_` 前缀
- 正则验证：`^[a-zA-Z0-9_\-\\]+$`

**阻止的攻击示例**:
```javascript
// ❌ 这些将被拒绝
long.registry.write("..\\..\\Windows\\Run", "malware", "evil.exe");
long.registry.write("HKEY_LOCAL_MACHINE\\SOFTWARE\\...", "key", "value");
```

---

### 6. ADS 流名称注入 ✅

**修复方法**:
- 验证流名称不包含特殊字符：`:`, `\`, `/`, `..`, `<`, `>`, `|`, `*`, `?`
- 长度限制：255 字符

---

### 7. 并发写入风险 ✅

**修复方法**:
- 在读锁内完成 JSON 序列化，释放锁后再写文件
- 原子写入：临时文件 → `File.Move` 替换
- 错误处理和临时文件清理

---

### 8. Nullable 警告 ✅

**修复方法**:
- 将 `_webView` 字段声明为 `WebView2 _webView = null!;`

## 🔄 插件开发者迁移指南

### HTML/JS 插件

**必须在 `manifest.json` 中声明 capabilities**:

```json
{
  "id": "my-plugin",
  "name": "我的插件",
  "version": "1.0.0",
  "runtime": "webview",
  "entryPoint": "index.html",
  "capabilities": [
    "system.clipboard",
    "fs.ads.access",
    "network.http",
    "shell.execute"
  ]
}
```

**Capability 参考表**:

| Capability | 允许的 API |
|---|---|
| `system.clipboard` | `long.clipboard.*` |
| `fs.ads.access` | `long.fs.ads.*` |
| `system.registry.write` | `long.registry.*` |
| `system.hotkey` | `long.hotkey.*` |
| `network.http` | `long.http.*` |
| `shell.selection` | `long.shell.getActiveFolder`, `getSelectedItems` |
| `shell.execute` | `long.shell.openFolder`, `openWithDefault` |
| `shell.execute.url` | `long.shell.openUrl` |
| `system.screenshot` | `long.screenshot.*` |
| `system.notification` | `long.ui.showToast` |
| `window.info` | `long.window.getForeground` |
| `file.ops` | `long.shell.listFiles`, `renameFile` |

**注意**: `storage.*` 无需声明，所有插件都可使用。

---

### C# 脚本插件 (.csx)

**不能直接使用系统命名空间**:

```csharp
// ❌ 不再可用
using System.IO;
var text = File.ReadAllText("file.txt");
Process.Start("notepad.exe");

// ✅ 使用宿主 API
var result = await Host.FileOps.ReadFileAsync("file.txt");
if (result.IsSuccess)
{
    var text = result.Data;
}

var processResult = await Host.Process.StartAsync("notepad.exe");
```

## 📊 测试覆盖

建议添加以下单元测试：

```csharp
[Fact]
public async Task WebPlugin_WithoutCapability_ShouldRejectApiCall()
{
    var manifest = new PluginManifest 
    { 
        Id = "test", 
        Capabilities = new List<string>()
    };
    var runtime = new WebPluginRuntime(manifest, ".");
    
    // 模拟调用需要权限的 API
    var result = await CallJsMethod(runtime, "long.registry.write", "key", "value");
    
    Assert.False(result.success);
    Assert.Contains("未声明权限", result.error);
}

[Fact]
public void RegistryService_PathTraversal_ShouldThrow()
{
    var service = new RegistryService();
    Assert.Throws<ArgumentException>(() => 
        service.WriteAsync("..\\..\\malicious", "name", "value"));
}

[Fact]
public async Task HttpService_InternalNetwork_ShouldReject()
{
    var service = new HttpService();
    var result = await service.GetAsync("http://192.168.1.1/");
    
    Assert.False(result.IsSuccess);
    Assert.Contains("内网", result.ErrorMessage);
}

[Fact]
public void ShellExecuteService_DangerousProtocol_ShouldReject()
{
    var service = new ShellExecuteService();
    var result = await service.OpenUrlAsync("file:///C:/Windows/System32/cmd.exe");
    
    Assert.False(result.IsSuccess);
    Assert.Contains("不支持的协议", result.ErrorMessage);
}
```
