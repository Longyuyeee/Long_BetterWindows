## 🏆 核心特性总览

### 1. 三语言热插拔 🔥
- **C# 脚本** (.csx) - Roslyn 沙盒执行
- **JavaScript** (.js) - WebView2 运行时
- **TypeScript** (.ts) - 自动编译支持
- **拖放安装** - 30 秒从想法到运行

### 2. 原子化能力系统 ⚛️
- **13 种能力 API**: clipboard / hotkey / registry / http / screenshot / storage / shell / ads / notification / theme / window
- **权限声明强制检查**
- **API 调用统计**
- **安全等级可视化**

### 3. 完整插件生态 🌐
- **插件市场** - 搜索、安装、更新
- **自动更新检测**

- **权限可视化** - 13 种能力图标
- **.lpak 打包格式**

- **双主题** - 浅色/深色平滑切换
- **响应式布局** - 适配 800px-1920px

### 5. 性能监控 📊
- **实时 CPU/内存监控**

## 🚀 技术亮点

### 架构设计
- **模块化插件系统** - PluginLoader + PluginScanner + PluginStore
- **三运行时隔离** - DLL / C# Script / WebView2
- **能力 API 抽象** - 13 个独立服务
- **依赖解析算法** - 拓扑排序 + DFS 环检测

### 安全机制
- **权限声明强制检查**
- **C# 脚本沙盒隔离**
- **WebView2 权限检查**
- **路径注入防护**
- **SSRF 防护**

### 性能优化
- **异步 IO** - 所有文件操作
- **缓存机制** - 插件市场 1 小时缓存
- **批量操作** - RollbackEngine 批量写入
- **GPU 加速** - 所有动画使用硬件加速

### UI/UX 设计
- **设计系统** - 统一颜色/间距/圆角
- **动画系统** - 10 种核心动画
- **图标系统** - 50+ emoji 图标映射
- **响应式** - 三档断点适配
