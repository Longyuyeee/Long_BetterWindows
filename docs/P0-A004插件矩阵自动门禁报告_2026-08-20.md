# P0-A004 插件矩阵自动门禁报告

> 日期：2026-08-20
> 范围：插件矩阵 schema v2 报告、自动门禁计数和发布资格算法

## 开发结果

- 新增 `schemas/plugin-positive-matrix-report.schema.json`，真实报告由 JsonSchema.Net 校验。
- 87 条自动证据绑定转换为 87 个稳定 gate；每个通过 gate 绑定证据路径、符号和真实 SHA-256。
- 报告新增 `automated_gate_count`、`passed_gate_count`、`failed_gate_count`、`environment_blocked_gate_count`、`not_run_gate_count` 和 `not_applicable_gate_count`。
- 新增共享资格函数 `automated-acceptance-policy.ps1`。只有合同有效、源码干净、无 failed/blocked/not-run，且所有 gate 为 passed 或 not_applicable 时才可发布。
- 旧人工报告字段仅作为 A005/A006 的临时兼容别名保留，固定值或由新 gate 计数派生，不参与资格判断。

## 审计结论

A004 本地目标已满足：插件矩阵发布资格已经由自动 gate、合同和源码状态决定，人工回执字段无法改变结果。A005 应迁移最终收口报告，使其直接消费 schema v2 gate 集合，并移除对兼容别名的依赖。
