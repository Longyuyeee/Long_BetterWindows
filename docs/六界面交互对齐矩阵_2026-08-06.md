## 共享状态合同

三种面板呈现必须复用同一 `ContextSnapshot`、搜索协调器和偏好数据，不建立三套结果引擎。跨面板状态最少包含：首次唤起前窗口、上下文快照、查询、当前结果 ID。状态仅在内存中一次性交接，消费后清除，不写入日志、JSON、设置或证据文件。

状态流转为：`原应用 -> 紧凑/上下文面板 -> 展开搜索 -> 执行动作或关闭 -> 原应用`。展开动作不得把紧凑面板自身当成原应用，不得重新读取已经变化的剪贴板或前台窗口，也不得在增量搜索首批结果到达时永久覆盖原选择。
