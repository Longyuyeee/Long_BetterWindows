## 开发结果

- verify-external-release-gate.ps1 改为消费 A006 schema v3 自动产品验收包，不再读取 reviewer、approval、receipt、Marketplace 人工演练或外部延期签字。
- 新增 automated_release_channel_policy schema v1。报告绑定当前提交、dirty 状态、A006 闭包、Release EXE 哈希及真实 Authenticode 状态。
- unsigned + offline 是可独立验证的本地主通道：宿主必须实际未签名，外部市场按策略关闭，缺少商业证书、生产 Registry/CDN 或其他仓库不会新增产品失败。
- test_service 仅接受回环 HTTPS，要求 SHA-256 固定服务证书，并真实获取 registry.json 与包内容、复算字节数和哈希；Registry 必须声明 registry/package/rollback/offline fallback 四项测试能力。
- production 不接受伪造通过或人工签字，缺少真实生产配置时如实记录 blocked_environment。
