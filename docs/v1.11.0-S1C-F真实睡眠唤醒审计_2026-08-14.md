## 需求对齐

- 只接受宿主窗口真实收到的 `WM_POWERBROADCAST`：`PBT_APMSUSPEND` 后必须出现 `PBT_APMRESUMESUSPEND` 或 `PBT_APMRESUMEAUTOMATIC`。
- 锁屏/解锁和质量测试使用的可用性注入不能生成物理电源证据。
- 恢复后必须保持插件 session ID、WebView 内容身份和嵌入表面，并恢复宿主可见性与交互状态。
- 探针结束前必须停止插件会话并确认清理，报告同时保留挂起前与恢复后的资源样本。
- 脚本只允许从干净跟踪树启动，已有 ready/report 文件不可覆盖；超时后只终止本次启动的宿主进程树。

## 实现

- `HostEnvironmentStateService` 新增明确的物理电源转换事件，同时保留现有统一交互可用性合同。
- `PhysicalPowerRecoveryQualityProbe` 打开硬件监控 WebView，等待真实挂起/恢复序列并生成 schema 1 JSON。
- 新增启动参数 `--quality-power-recovery-report` 和 `verify-sleep-wake-recovery.ps1`。
- 脚本支持维护者从 Windows 电源菜单手动睡眠；显式传入 `-TriggerSleep` 时调用 `SetSuspendState` 触发真实系统睡眠，不提供模拟消息路径。
