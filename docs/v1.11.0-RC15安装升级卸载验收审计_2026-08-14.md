## 1. 结论

RC15 unsigned 当前用户安装器已通过本机可执行的安装、安装后桌面自动化、卸载、RC2→RC15 原位升级、RC15→RC2 回退和数据保留检查。安装器退出码、版本身份、卸载登记和目录均正确；卸载后没有宿主、WebView2、产品文件或卸载登记残留；原有 RC2 安装登记和用户数据已恢复。

本轮关闭 S3 的“本机当前用户安装器自动生命周期”子项，但不冒充干净 Windows、新用户、SmartScreen、杀毒软件、真实读屏、人工托盘/任务栏观察或 25 / 25 插件人工回执。Windows Sandbox 未安装，当前机器也没有第二个可用的验收环境，因此 S5 人工门禁和 S6 隔离环境门禁仍保持未完成。

## 2. 安全边界与恢复措施

本机原有 `1.11.0-rc.2` 安装登记指向 `E:\long\Long助手\`。为避免覆盖原安装，本轮采取以下措施：

1. 验收前导出原 RC2 当前用户卸载登记；
2. 确认没有 `LongBetterWindows.Host` 进程后，把 `%LOCALAPPDATA%\LongBetterWindows` 临时移动到被忽略的本地证据目录；
3. 使用 `/NOICONS` 和显式 `/DIR` 把 RC15 安装到 `artifacts/quality/` 下的独立目录，不修改现有快捷方式；
4. 卸载验收后恢复原用户数据和 RC2 卸载登记；
5. 再次核对原 RC2 宿主、卸载器、安装路径和主题文件均存在，宿主进程数为 0。

原始报告、登记备份和测试标记仅位于被忽略的 `artifacts/quality/rc15-installer-lifecycle-20260814/`，不提交 Git。

## 7. 仍未关闭的门禁

1. 本轮安装器来自本地候选目录，没有互联网来源标记，不能验证 unsigned 包的 SmartScreen 或杀毒软件行为；
2. 当前账户不是新 Windows 用户，不能使用 `-ConfirmCleanUserEnvironment` 生成正式干净环境证据；
3. Windows Sandbox 未安装，也没有第二台电脑；隔离环境验收仍待可用环境或显式延期决策；
4. 托盘、任务栏、真实读屏、亮暗主题逐页视觉和 25 / 25 插件仍需人工回执；
5. 本轮没有创建正式 `1.11.0` 身份、标签或 Release，也没有修改 RC15 候选资产。
