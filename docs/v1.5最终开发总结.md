## 🆕 全部新增能力（6项）

### 1. system.clipboard.monitor — 剪贴板变更监听 ✅
**实现**: Windows Clipboard Chain API  
**API**: StartMonitoring / StopMonitoring / ClipboardChanged 事件

### 2. network.ports — 端口与进程映射 ✅
**实现**: IPGlobalProperties + GetExtendedTcpTable Win32 API  
**API**: GetTcpConnections / GetTcpListeners / GetUdpEndpoints / FindPortOwner

### 3. system.performance — 系统性能监控 ✅
**实现**: PerformanceCounter + GlobalMemoryStatusEx Win32 API  
**API**: GetCpuUsage / GetMemoryInfo / GetDiskInfo / GetSystemInfo / GetTopProcesses

### 4. filesystem.advanced — 高级文件系统 ✅
**实现**: Directory/File API + MD5 哈希  
**API**: EnumerateFiles / ComputeFileHash / FindDuplicateFiles / BatchRename / ClassifyFiles / SearchFileContent

### 5. text.pinyin — 拼音匹配与转换 🆕
**实现**: 拼音映射表 + 模糊匹配算法  
**API**: 
```csharp
Task<HostApiResponse<string>> GetPinyinAsync(string text);
Task<HostApiResponse<string>> GetPinyinInitialsAsync(string text);
Task<HostApiResponse<bool>> MatchAsync(string text, string query);
Task<HostApiResponse<List<PinyinMatchResult>>> FilterAsync(List<string> items, string query);
```

**特色**:
- 支持全拼匹配（"文件" → "wenjian"）
- 支持首字母匹配（"文件" → "wj"）
- 智能评分排序（直接匹配 > 全拼 > 首字母）

---

### 6. system.cache — 系统缓存清理 🆕
**实现**: File API + SHEmptyRecycleBin Win32 API  
**API**:
```csharp
Task<HostApiResponse<CleanupResult>> CleanTempFilesAsync();
Task<HostApiResponse<CleanupResult>> CleanWindowsUpdateCacheAsync();
Task<HostApiResponse<CleanupResult>> CleanBrowserCacheAsync(string browser);
Task<HostApiResponse<CleanupResult>> EmptyRecycleBinAsync();
Task<HostApiResponse<CacheStatistics>> GetCacheStatisticsAsync();
Task<HostApiResponse<CleanupSummary>> CleanAllAsync();
```

**清理目标**:
- 系统临时文件（%TEMP%）
- Windows 更新缓存
- 浏览器缓存（Chrome/Edge/Firefox）
- 回收站
