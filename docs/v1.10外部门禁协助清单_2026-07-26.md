## 1. 需要项目负责人决定

### 1.1 正式市场是否随 v1.10 上线

请选择其一：

- **随 v1.10 上线**：需要提供受控 HTTPS Registry/CDN 根地址、正式信任库文件，并在执行环境配置 `LONG_MARKETPLACE_DEPLOY_TOKEN`。演练会真实部署候选、公开验证、回滚并再次验证。
- **本版保持本地目录模式**：需要书面确认远程市场不属于 v1.10 正式发布范围；产品仍保留本地 `.lpak` 导入、签名审查和未来远程市场能力。

没有此决定时，统一外部发布决策器无法完成 Marketplace 输入。

### 1.2 测试组织方式

下载门禁要求操作人与审核人不同；干净 Windows 门禁要求审核人与采集 Windows 账户不同。请确认至少两位实际人员可以参与，不能使用自动生成姓名或由同一人兼任。

## 2. 需要负责人或测试人员操作

### 2.1 真实浏览器下载

下载：

[`LongBetterWindows-v1.10.0-win-x64-self-contained.zip`](https://github.com/Longyuyeee/Long_BetterWindows/releases/download/v1.10.0-rc.2/LongBetterWindows-v1.10.0-win-x64-self-contained.zip)

下载后不要复制、重新压缩或移除文件来源信息。把下载文件的完整路径告诉开发执行者，即可自动核验：

- SHA-256 与字节数；
- GitHub HTTPS 来源；
- Windows `Zone.Identifier` 与 `ZoneId=3`；
- 来源 URL 脱敏。

随后需要两位人员分别记录解压方式、SmartScreen、杀毒软件和首次启动观察。

当前自动化环境的内置浏览器不保留系统下载文件，本机 Chrome 未运行且未安装 ChatGPT Chrome Extension，因此无法代替这一步。

### 2.2 干净 Windows 生命周期

在新建 Windows 用户或一次性 Windows 11 x64 虚拟机中：

1. 确保候选从未启动且没有残留安装。
2. 运行自包含 ZIP 的自动采集脚本。
3. 实际观察首次启动、托盘、`Alt + Space`、WebView2。
4. 验证并行升级数据保留、回滚旧版本和卸载集成清理。
5. 由不同人员审核并签名。

日常开发账户不能声明为干净环境。

### 2.3 物理 DPI

正式矩阵仍需真实 100% / 125% / 150% / 200% Windows 显示缩放，每档采集亮暗主题和四类视图共 8 张，并人工检查清晰度、裁切、焦点和 Web 内容。

当前已完成 250% 扩展自动证据，但它不是正式矩阵成员。

### 2.4 辅助功能

需要在 Windows 真实设置下分别采集：

- 高对比度；
- 减少动画；
- 高对比度与减少动画组合。

至少一组必须真实运行 Narrator 或 NVDA，并由人员确认键盘导航、焦点可见、动效行为和朗读内容。

当前电脑处于普通主题、动画开启且没有运行读屏器，不能生成这些正式证据。

## 3. 暂不阻塞的可选增强

这两项继续保留工程能力，但不阻塞当前 unsigned 主产品候选。
