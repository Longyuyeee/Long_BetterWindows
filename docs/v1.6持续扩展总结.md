## 🆕 全部新增能力（8项）

### 1. system.clipboard.monitor — 剪贴板变更监听
**实现**: Windows Clipboard Chain API

### 2. network.ports — 端口与进程映射
**实现**: IPGlobalProperties + GetExtendedTcpTable Win32 API

### 3. system.performance — 系统性能监控
**实现**: PerformanceCounter + GlobalMemoryStatusEx Win32 API

### 4. filesystem.advanced — 高级文件系统
**实现**: Directory/File API + MD5 哈希

### 5. text.pinyin — 拼音匹配与转换 🆕
**实现**: 拼音映射表 + 模糊匹配算法
**API**: GetPinyin / GetPinyinInitials / Match / Filter

### 6. system.cache — 系统缓存清理 🆕
**实现**: File API + SHEmptyRecycleBin Win32 API
**API**: CleanTempFiles / CleanWindowsUpdateCache / CleanBrowserCache / EmptyRecycleBin

### 7. system.schedule — 定时任务 🆕
**实现**: System.Timers.Timer
**API**:
```csharp
Task<HostApiResponse<string>> CreateTaskAsync(ScheduleTask task);
Task<HostApiResponse> DeleteTaskAsync(string taskId);
Task<HostApiResponse<List<ScheduleTask>>> GetAllTasksAsync();
Task<HostApiResponse> SetTaskEnabledAsync(string taskId, bool enabled);
Task<HostApiResponse> RunTaskNowAsync(string taskId);
```

**特色**:
- 支持一次性任务（once）
- 支持周期任务（interval）
- 支持命令执行、通知等操作

### 8. system.audio — 音频控制 🆕
**实现**: waveOutGetVolume/waveOutSetVolume Win32 API
**API**:
```csharp
Task<HostApiResponse<int>> GetVolumeAsync();
Task<HostApiResponse> SetVolumeAsync(int volume);
Task<HostApiResponse<bool>> GetMuteAsync();
Task<HostApiResponse> SetMuteAsync(bool mute);
Task<HostApiResponse<int>> IncreaseVolumeAsync(int step = 5);
Task<HostApiResponse<int>> DecreaseVolumeAsync(int step = 5);
Task<HostApiResponse<List<AudioDevice>>> GetAudioDevicesAsync();
Task<HostApiResponse> SetDefaultDeviceAsync(string deviceId);
```

**特色**:
- 获取/设置系统音量（0-100）
- 静音/取消静音
- 音量增减控制
- 音频设备管理
