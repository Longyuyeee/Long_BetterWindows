## 1. 需求对齐

本批验证总计划 S1C 的“前台、隐藏、托盘交替”，不新增 UI、插件功能或 uTools 兼容层。
与原后台可见性探针不同，本批实际经过生产窗口与托盘代码路径：

```text
Window.Close
  → MainWindow.Closing
  → TrayService 拦截关闭并隐藏窗口
  → WebView 宿主可见性变为 false
  → TrayService 生产主操作回调
  → 窗口恢复、归一化并激活
  → WebView 宿主可见性恢复为 true
```

探针打开硬件监控真实 Web 插件，连续执行 8 轮上述路径，并验证资源趋势和最终清理。

## 5. 审计边界与下一步

真实托盘恢复范围已关闭。自动环境通知门禁和托盘门禁仍不能替代以下 Windows 物理操作：

1. 锁屏后解锁；
2. 睡眠后唤醒；
3. 显示器拔插或显示拓扑变化；
4. 物理 DPI 改变后的窗口约束和焦点检查。

这些操作会中断当前用户会话或依赖实际显示器条件，继续保持 `pending`。下一步按顺序先执行
锁屏/解锁，再执行睡眠/唤醒，最后根据当前显示器条件执行拓扑和 DPI 验收；每项都必须记录
操作前后状态，不得用自动等价通知写成物理通过。
