# Long助手辅助功能发布验收

> 更新日期：2026-08-21
> 目标：在真实 Windows 设置下验证键盘输入、UIA 焦点事件和动态公告事件。

## 配置矩阵

分别准备并重启应用：

1. `high_contrast`：开启高对比度、保持动画开启。
2. `reduced_motion`：关闭高对比度、关闭动画效果。
3. `combined`：开启高对比度并关闭动画效果。

采集器读取实际系统状态，声明与实际状态不一致时立即失败。Narrator/NVDA 可用于探索体验，但发布判定依赖可重复验证的 Windows UI Automation 事件，不依赖人工签字。

## 采集

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\capture-accessibility-evidence.ps1 `
  -OutputDirectory .\artifacts\accessibility-physical-high-contrast-YYYYMMDD `
  -ExpectedProfile high_contrast `
  -ExpectedSourceCommit "完整的 40 位候选源码提交" `
  -ScreenReader None
```

其余配置替换为 `reduced_motion` 和 `combined`。采集器执行真实桌面 UI 自动化，要求 `SendInput` 键盘路径、搜索框 UIA 焦点事件和选中项 live-region 事件来自同一宿主进程，并保存报告、日志、系统设置和 SHA-256。Manifest 使用 schema v4、分类 `automated_physical_accessibility_evidence`。

## 汇总

```powershell
powershell.exe -ExecutionPolicy Bypass -File .\verify-accessibility-matrix.ps1 `
  -EvidenceDirectories `
    .\artifacts\accessibility-physical-high-contrast-YYYYMMDD, `
    .\artifacts\accessibility-physical-reduced-motion-YYYYMMDD, `
    .\artifacts\accessibility-physical-combined-YYYYMMDD `
  -ExpectedSourceCommit "完整的 40 位候选源码提交" `
  -OutputPath .\artifacts\quality\accessibility-release-matrix.json
```

汇总器要求三个唯一配置来自同一提交，真实设置吻合，三组 UIA 焦点/live-region 事件完整，报告与日志哈希未变化。输出使用 schema v5、分类 `automated_physical_accessibility_matrix`，并生成可移植 `.sources` 来源包。旧人工批准脚本和 reviewer/checklist 字段已退役。
