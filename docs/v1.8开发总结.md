## 🆕 本次新增能力（3项）

### 1. system.wallpaper — 壁纸管理 🆕

**实现**: Windows Registry API + SystemParametersInfo

**API**:
```csharp
Task<HostApiResponse<string>> GetWallpaperAsync();
Task<HostApiResponse> SetWallpaperAsync(string path, WallpaperStyle style);
Task<HostApiResponse<WallpaperStyle>> GetWallpaperStyleAsync();
```

**功能亮点**:
- 获取当前壁纸路径
- 设置壁纸（支持多种样式）
- 壁纸样式：居中/拉伸/适应/填充/跨越/平铺

---

### 2. display.brightness — 屏幕亮度控制 🆕

**实现**: Windows Device I/O Control API

**API**:
```csharp
Task<HostApiResponse<int>> GetBrightnessAsync();
Task<HostApiResponse> SetBrightnessAsync(int brightness);
Task<HostApiResponse<int>> IncreaseBrightnessAsync(int step);
Task<HostApiResponse<int>> DecreaseBrightnessAsync(int step);
```

**功能亮点**:
- 获取/设置屏幕亮度（0-100）
- 亮度增加/减少
- 快捷键支持

---

### 3. network.monitor — 网络流量监控 🆕

**实现**: System.Net.NetworkInformation API

**API**:
```csharp
Task<HostApiResponse<NetworkStats>> GetNetworkStatsAsync();
Task<HostApiResponse<NetworkSpeed>> GetNetworkSpeedAsync();
Task<HostApiResponse<List<NetworkInterfaceInfo>>> GetNetworkInterfacesAsync();
```

**功能亮点**:
- 实时上传/下载速度
- 累计流量统计
- 网络接口信息
- 网卡状态监控

## 💡 应用场景

### 壁纸管理
- **壁纸轮换器**: 定时更换壁纸
- **场景切换**: 工作/娱乐不同壁纸
- **必应壁纸**: 自动下载每日壁纸
- **本地壁纸库**: 随机选择本地图片

### 亮度控制
- **护眼模式**: 自动调节亮度
- **定时调整**: 根据时间自动调节
- **快捷键**: 热键快速调节
- **场景联动**: 与主题联动调节

### 网络监控
- **实时网速**: 桌面显示当前网速
- **流量统计**: 每日/每月流量统计
- **网络诊断**: 监控网络状态
- **流量预警**: 超限提醒
