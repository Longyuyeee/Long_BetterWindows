## 📝 开发规范与质量保证

### 代码规范

1. **命名约定**
   - 接口：`IXxxService`
   - 实现类：`XxxService`
   - 能力 ID：`category.subcategory`（如：`system.hotkey`）

2. **注释要求**
   - 所有公共接口必须有 XML 文档注释
   - 复杂算法必须有行内注释说明

3. **异步编程**
   - 所有 I/O 操作必须异步
   - 避免 `.Result` 和 `.Wait()`，防止死锁
   - `async void` 仅用于事件处理器

### 测试要求

1. **单元测试**
   - 每个新能力必须有单元测试
   - 覆盖率目标：核心模块 80%+

2. **集成测试**
   - 插件加载流程端到端测试
   - 权限沙盒验证测试

3. **性能测试**
   - 启动时间 < 2 秒
   - 插件加载时间 < 500ms
   - 内存占用 < 200MB（含 20 个插件）

### 文档要求

1. **API 文档**
   - 接口签名 + 参数说明 + 返回值
   - C# 和 JavaScript 双语示例
   - 错误代码表

2. **用户文档**
   - 快速开始指南
   - 常见问题 FAQ
   - 视频教程（可选）

3. **开发者文档**
   - 插件开发指南
   - 最佳实践
   - 故障排查
