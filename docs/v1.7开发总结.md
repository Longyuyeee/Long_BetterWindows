## 🆕 本次新增能力（2项）

### 1. system.power — 电源管理 🆕

**实现**: Win32 API (ExitWindowsEx, SetSuspendState, LockWorkStation)

**API**:
```csharp
Task<HostApiResponse> ShutdownAsync(int delay = 0);
Task<HostApiResponse> RebootAsync(int delay = 0);
Task<HostApiResponse> SleepAsync();
Task<HostApiResponse> HibernateAsync();
Task<HostApiResponse> LockScreenAsync();
Task<HostApiResponse<PowerStatus>> GetPowerStatusAsync();
Task<HostApiResponse> PreventSleepAsync(bool prevent);
```

**功能亮点**:
- 关机/重启/睡眠/休眠
- 锁定屏幕
- 获取电源状态（电池电量、充电状态）
- 阻止系统休眠（适用于长时间任务）

---

### 2. system.theme — 主题管理 🆕

**实现**: Windows Registry API

**API**:
```csharp
Task<HostApiResponse<SystemTheme>> GetSystemThemeAsync();
Task<HostApiResponse> SetSystemThemeAsync(SystemTheme theme);
Task<HostApiResponse> ToggleThemeAsync();
Task<HostApiResponse<string>> GetAccentColorAsync();
Task<HostApiResponse> SetAccentColorAsync(string color);
```

**功能亮点**:
- 获取/设置系统主题（亮色/暗色）
- 一键切换暗色模式
- 获取/设置系统强调色
- 支持 Windows 10/11

## 💡 应用场景

### 电源管理
- **定时关机**: 结合 `system.schedule` 实现定时关机
- **一键锁屏**: 快捷热键锁定屏幕
- **防止休眠**: 下载/渲染等长时间任务时阻止休眠
- **电池监控**: 笔记本电量提醒

### 主题管理
- **护眼模式**: 定时切换暗色模式（夜间自动）
- **主题联动**: 根据时间/环境光自动切换主题
- **个性化**: 一键切换系统强调色
- **场景切换**: 工作/娱乐不同主题配置
