## 5. 仍需人工确认

1. 在 Windows 真实任务栏打开至少两个不同插件分离窗口，确认图标、分组和标题可区分；
2. 从任务栏切回插件窗口，确认焦点落点与前后模块连续性合理；
3. 主窗口关闭进入托盘后，确认托盘图标清晰，单击恢复、菜单命令和退出符合预期；
4. 在亮色/暗色、250% DPI 和实际多显示器布局下观察任务栏图标没有模糊、错误缩放或串组；
5. 与 Narrator/NVDA 验收结合，确认托盘/窗口状态变化的实际朗读体验。
