## 2. 安全边界与恢复措施

本机原有 `1.11.0-rc.2` 登记指向 `E:\long\Long助手\`。本轮采用以下隔离与恢复措施：

1. 导出当前用户卸载登记到本地证据目录；
2. 确认宿主未运行后，把 `%LOCALAPPDATA%\LongBetterWindows` 移动到本地证据备份；
3. 使用 `/NOICONS` 与显式 `/DIR`，把所有测试安装限制在 `artifacts/quality/rc16-installer-lifecycle-20260814/`；
4. 首次安装与升级/回退使用两个独立测试目录，不修改原 RC2 程序目录；
5. 最终导入原登记并移回原用户数据，复核路径、文件和主题哈希。

组合式长命令两次在执行前被安全策略拒绝，没有改变系统状态；流程随后拆成单一、可核对步骤完成。一个已确认文件数为 0 的空测试目录因同一安全策略没有删除，仅保留在被忽略的本地证据根内，不是产品残留。
