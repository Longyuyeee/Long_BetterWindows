
插件人工规划、会话启动、完成和批准脚本已在 A008 退役。历史回执不参与矩阵计算；探索性桌面测试只记录预期、实际、复现步骤和本地证据，不生成批准状态。

### 1. 启动.bat (Windows)
**用途**: 一键编译并启动应用

**功能**:
- 自动构建 Release 版本
- 复制所有 WebView 插件到输出目录
- 启动应用程序

**使用方法**:
```bash
双击 启动.bat
# 或在命令行运行
.\启动.bat
```

---

### 2. 打包发布.bat (Windows)
**用途**: 打包完整发布版本

**功能**:
- 构建 Release 版本
- 复制主程序和所有依赖
- 复制所有插件（DLL + WebView）
- 生成 README.txt 说明文件
- 输出到 `releases/v{版本号}/` 目录

**使用方法**:
```bash
双击 打包发布.bat
# 打包完成后，可以压缩 releases 目录进行分发
```

**输出目录结构**:
```
releases/v1.6.0/
├── LongBetterWindows.Host.exe
├── *.dll
├── Plugins/
│   ├── DLL 插件/
│   └── WebView 插件/
└── README.txt
```

---

### 3. 开发模式.bat (Windows)
**用途**: 开发调试模式

**功能**:
- 构建 Debug 版本
- 启动应用并显示详细日志
- 支持插件热重载

**使用方法**:
```bash
双击 开发模式.bat
# 或在命令行运行
.\开发模式.bat
```

---

### 4. 启动.sh (Linux/macOS)
**用途**: 跨平台启动脚本

**功能**:
- 与 Windows 版本功能相同
- 适用于 Linux/macOS 环境

**使用方法**:
```bash
chmod +x 启动.sh
./启动.sh
```

---

## 🎯 快速开始

### 新用户
1. 双击 `启动.bat` - 首次会自动编译，之后直接启动
2. 使用 `Ctrl+Space` 打开工具中心

### 开发者
1. 双击 `开发模式.bat` - 启动开发模式
2. 修改插件后会自动热重载

### 发布版本
1. 双击 `打包发布.bat` - 生成发布包
2. 压缩 `releases/v1.6.0/` 目录
3. 分发 ZIP 文件

---

## 📝 注意事项

1. **首次运行**
   - 首次运行会自动编译，耗时约 30 秒
   - 需要 .NET 8.0 SDK

2. **插件开发**
   - WebView 插件修改后直接刷新即可
   - DLL 插件需要重新编译

3. **发布打包**
   - 打包会生成完整的独立版本
   - 包含所有依赖和插件
   - 可直接在其他 Windows 电脑运行

4. **权限要求**
   - 部分功能需要管理员权限（端口管理、系统清理）
   - 建议以管理员身份运行

## 🔧 故障排查

### 构建失败
```bash
# 清理并重新构建
dotnet clean
dotnet restore
dotnet build
```

### 插件未加载
```bash
# 检查插件目录
dir src\LongBetterWindows.Host\bin\Release\net8.0-windows\Plugins

# 手动复制插件
xcopy /E /Y src\DevToolkit bin\Release\net8.0-windows\Plugins\DevToolkit\
```

### 应用启动失败
```bash
# 使用开发模式查看详细日志
.\开发模式.bat
```
