# .NET 原生插件扩展边界设计（PX3C）

> 状态：PX3C 审计基线
>
> 原则：Contracts SDK 只承载稳定合同，不把宿主窗口、服务实现或协调器伪装成公共 API

## 当前结果

`LongBetterWindows.PluginSdk` 已承载生命周期、命令、语言、Manifest、响应模型和 27 项宿主能力。`LongBetterWindows.PluginSdk.Testing` 提供不引用 WPF 宿主的 `PluginTestHost` 与 `PluginContractHarness`，覆盖：

- Manifest 身份与版本；
- Loaded → Running → Stopped 生命周期；
- 命令调用；
- 语言切换；
- 两次资源释放；
- 与生产一致的能力拒绝和测试替身注册。

ClipboardHistory 原生后台和 SamplePlugin 已只引用 SDK。机器可读现状以 [`native-plugin-boundary-audit.json`](native-plugin-boundary-audit.json) 为准，质量门禁要求它与实际 `.csproj` 宿主引用完全一致。

## 剩余六项耦合

| 插件 | 宿主依赖 | 不能直接放入 Contracts SDK 的原因 |
|---|---|---|
| FolderNote | Floating HUD、热键设置控件 | 属于具体 WPF 视觉实现 |
| Macro | Floating HUD、热键设置控件 | 同时绑定宿主资源字典与活动 UI |
| WindowManager | Floating HUD、热键设置控件 | 属于具体 WPF 视觉实现 |
| ColorPicker | HUD、设置控件、异步投递、屏幕取色 | 混合 UI、调度与原生采样实现 |
| Screenshot | HUD、设置控件、异步投递 | 混合 UI 与线程投递实现 |
| QuickLaunch | `ISearchProvider`、宿主搜索模型 | 当前 DTO 依赖宿主 `ContextSnapshot` 和内部动作路由 |

## 目标边界

### 1. 通知与状态反馈

普通 Toast 全部改用现有 `INotificationService`，不再让插件调用 `FloatingHudWindow.ShowToast`。需要可编辑 HUD 的 FolderNote 保留插件自有窗口，或使用后续 WPF UI Kit 的公开组件；不把宿主窗口类放入 SDK。

### 2. WPF Plugin UI Kit

建立独立 `LongBetterWindows.PluginSdk.Wpf`，允许依赖 WPF，但不得反向引用宿主。首批只包含：

- 基于动态 Design Token 的热键设置控件；
- 插件窗口主题资源适配器；
- 可组合的状态提示和表单行。

宿主与原生插件共同引用该 UI Kit。Contracts SDK 继续保持无宿主实现依赖。

### 3. 原生采样与异步投递

- 将 `AsyncDeliveryBoundary` 抽象为无宿主状态的 SDK 工具，并保留异常、取消和一次性交付测试。
- 屏幕取色通过新的 `IScreenColorSampler` 能力或 `IScreenCaptureService` 的像素采样扩展暴露；插件不直接引用宿主 `ScreenColorSampler`。

### 4. 搜索扩展

在 SDK 定义不依赖 `ContextSnapshot` 的 `IPluginSearchProvider`、`PluginSearchRequest`、`PluginSearchResult` 和声明式动作。宿主负责把公共 DTO 映射到内部搜索排序及工作区路由。QuickLaunch 迁移后，旧 `ISearchProvider` 保持宿主内部接口。

## 后续实施顺序

1. PX3D-A（已完成）：迁移剩余普通 Toast，抽出异步投递工具和 WPF 热键设置 UI Kit；宿主引用由 6 项降为 3 项。
2. PX3D-B（已完成）：增加屏幕像素采样合同与锚点编辑 Surface，迁移 ColorPicker 与 FolderNote；宿主引用降为 1 项。
3. PX3D-C（已完成）：增加公共搜索 DTO/接口，迁移 QuickLaunch；原生插件宿主项目引用清零。
4. 每一批均更新机器审计文件；完成标准为 `rg` 不再找到任何原生插件对 `LongBetterWindows.Host.csproj` 的引用。

这套顺序优先复用现有能力并隔离视觉实现，避免为了快速清零引用而扩大 Contracts SDK 的不稳定表面。
