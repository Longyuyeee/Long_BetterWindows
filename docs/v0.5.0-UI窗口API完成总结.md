## ✅ 实现的功能

### 1. UI 能力接口定义
**文件**: `src/LongBetterWindows.Host/Capabilities/IUICapability.cs`

```csharp
public interface IUICapability
{
    // 创建自定义窗口
    Task<HostApiResponse<string>> CreateWindowAsync(
        string title, 
        string htmlContent, 
        int width = 600, 
        int height = 400, 
        bool resizable = true
    );
    
    // 关闭窗口
    Task<HostApiResponse> CloseWindowAsync(string windowId);
    
    // 向窗口发送消息
    Task<HostApiResponse> SendMessageToWindowAsync(
        string windowId, 
        string message
    );
    
    // 获取所有打开的窗口 ID
    Task<HostApiResponse<List<string>>> GetOpenWindowIdsAsync();
}
```

## 🎯 技术亮点

### 1. 线程安全
所有 UI 操作都通过 `Application.Current.Dispatcher` 调度到 UI 线程：

```csharp
await Application.Current.Dispatcher.InvokeAsync(() =>
{
    var window = new Window { /* ... */ };
    window.Show();
});
```

### 2. 窗口生命周期管理
```csharp
private readonly Dictionary<string, Window> _windows = new();

window.Closed += (s, e) =>
{
    lock (_lock)
    {
        _windows.Remove(windowId);
    }
};
```

### 3. 消息通信机制
- **宿主 → 窗口**: 通过 `CoreWebView2.ExecuteScriptAsync()` 触发自定义事件
- **窗口 → 宿主**: 通过 `chrome.webview.postMessage()`（需插件自行监听）

```javascript
// 窗口内监听宿主消息
window.addEventListener('hostMessage', (event) => {
    const data = event.detail;
    console.log('收到消息:', data);
});
```

### 4. 输入验证
```csharp
if (width < 200 || width > 3840)
    return HostApiResponse<string>.Failure(
        ApiErrorCode.InvalidArgument, 
        "窗口宽度必须在 200-3840 之间");
```

## 📋 权限声明

插件使用 UI 窗口 API 需要在 `manifest.json` 中声明：

```json
{
  "id": "my-plugin",
  "name": "我的插件",
  "capabilities": [
    "ui.window"
  ]
}
```
