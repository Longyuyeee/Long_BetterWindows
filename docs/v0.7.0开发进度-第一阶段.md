### 任务 #16: 插件一键安装功能 ✅
**文件**:
- `Services/PluginInstallService.cs` - 插件安装服务

**功能**:
- `InstallFromMarketAsync()` - 从市场下载并安装
  - 显示下载进度（百分比）
  - 自动调用 LpakInstallerService
  - 触发热加载（文件系统监视器）
  - Toast 提示安装结果
- `UpdatePluginAsync()` - 更新插件
  - 卸载旧版本
  - 安装新版本
- `IsPluginInstalled()` - 检查是否已安装
- `GetInstalledVersion()` - 获取已安装版本

**安装流程**:
1. 下载插件 → 显示进度
2. 保存到临时文件
3. 调用 LpakInstallerService 安装
4. 等待文件系统监视器触发热加载
5. 显示成功/失败提示
6. 更新按钮状态（✓ 已安装）

**错误处理**:
- 网络错误 → 提示"下载失败：网络错误"
- 安装失败 → 显示具体错误信息
- 临时文件清理
