## 迁移准入标准

每个内置插件完成迁移时必须同时满足：

- 使用统一 `PluginWindowHost` 和清单窗口规格。
- 声明至少一个可发现、可执行的功能指令。
- Web 页面使用 Long Web UI Kit，不在页面内维护颜色体系。
- 支持暗色/亮色主题、键盘主流程、焦点状态和状态播报。
- 命令入口可以消费文本、剪贴板、文件或 Explorer 选区等声明式上下文。
- 通过清单解析、静态 UI 约束、构建和运行验收。

## 第一批实现基线

- 公共 UI Kit 新增页面、标题、双栏、字段、工具栏、结果、选项、快捷键等布局组件。
- 公共 `LongUI.onCommand` 将宿主 `long.command` 消息转化为稳定的插件命令订阅接口。
- WebView2 改为首次打开时延迟初始化，启动扫描不再阻塞于第一个 Web 插件。
- 插件扫描延后到主窗口与热键服务就绪后执行，当前可发现并注册 20 / 20 个插件、37 条命令。
- Base64 与 JSON 支持从命令中心直接带入文本或剪贴板内容并立即处理。
- 密码生成器使用 `crypto.getRandomValues`，替代非安全的 `Math.random`。
- 三个插件均支持 `Ctrl + Enter` 主操作、焦点可见性和 `aria-live` 状态播报。

## 后续执行顺序

20 个内置插件已经全部完成迁移。新增四个 Web 插件使用 Long Web UI Kit、命令桥、键盘主流程、`aria-live` 和显式生命周期声明，并通过真实 WebView 截图检查。阶段 5 的性能、可访问性、主题、动效与工程视觉质量验收已经完成，物理 DPI 设备矩阵继续保留人工签核。

热键冲突不再导致相关插件进入 Error：Macro 与 Screenshot 均具备备用组合，FolderNote 与 WindowManager 保留命令中心兜底入口。

## 第二批实现基线

- 快速便签使用安全 DOM 构建历史列表，支持本地持久化、预览、编辑、删除和命令上下文预填。
- 翻译工具不再直接使用页面 `fetch`，改由声明式 `network.http` 能力和宿主 HTTP 服务发起请求。
- 文本对比使用 LCS 按行对齐新增与删除，支持交换、粘贴和复制统一 Diff。
- Web API 桥返回协议统一为小写 `success/data/error`。
- Web 消息处理恢复对应插件的 `PluginAccessContext`，能力调用重新进入权限检查链路。

## 第三批实现基线

- 剪贴板工具箱使用安全 DOM 列表、可见性监控和本地历史/固定数据，不再声明未消费的全局热键。
- Markdown 预览使用节点级安全渲染，链接只接受 HTTP、HTTPS 和 mailto 协议。
- 批量重命名只读取明确 Explorer 选区，不再隐式扩展到整个文件夹。
- 重命名声明 `file.ops`，并由宿主 `IFileOpsService` 执行移动操作。
- 新文件名在执行前检查非法字符、尾随点/空格和批次内重名；失败项保留以便重试。
- 全部 9 个 Web 插件均具备命令、窗口规格、主题同步、键盘主流程和状态播报。

## 第四批实现基线

- 快捷启动器作为命令中心中的深层搜索能力，不再争夺第二个全局唤起热键；可消费命令输入作为初始查询。
- 快捷启动器搜索窗口使用 Long 搜索框、命令项、徽标、渐变强调与统一运动令牌。
- 宏录制 HUD 使用语义化录制/播放/空闲状态，支持减少动画，并在首选热键冲突时自动降级。
- 颜色拾取 HUD 使用语义化卡片与实时色样，通过全局鼠标按下确认取色，修复偏移窗口无法可靠点击的问题。
- 颜色值通过宿主剪贴板能力写入，不再绕过权限链路。
- 三个原生插件项目会在构建后同步 DLL 与清单到宿主实际扫描目录，解决运行时加载旧二进制的问题。
- 自动化约束覆盖原生 XAML 语义色、命令清单、热键降级和宿主能力调用；当前 64 项测试全部通过。

## 内容状态统一批次

| 批次 | 插件/范围 | 已统一状态 | 状态 |
|---|---|---|---|
| S1 | Long Web UI Kit | `empty`、`loading`、`error`、可选重试、`aria-live`、`aria-busy`、减少动画 | 已完成 |
| S1 | PortManager | 初始加载、空列表、搜索无结果、加载失败、重试 | 已完成 |
| S1 | ClipboardHistory | 初始加载、无历史、筛选无结果 | 已完成 |
| S2 | HardwareMonitor、ClipboardTool、RegexTester | 系统/列表加载、空结果、失败详情、重试、安全动态文本 | 已完成 |
| S3 | FileRenamerPlugin、QuickNotePlugin、MarkdownPreview | Explorer 选区、便签历史和预览空态；全仓私有状态清理 | 已完成 |

状态组件由宿主注入的 `LongUI.renderState` 创建，动态文本只通过 DOM `textContent` 写入。插件可以提供标题、详情和重试动作，但不得覆盖三态的角色、播报优先级或忙碌语义。

完成门禁：所有内置 Web `index.html` 均不得包含 `long-empty`、`.empty-state` 或私有 `.loading` 内容状态。翻译、复制、保存等按钮触发的短时结果继续使用 `long-status`，避免把操作反馈误建模为占据内容区的加载页。

## 第五批实现基线

- 截图工具的区域选择器改为语义化 XAML 浮层，展示操作引导、选择范围和实时尺寸；多显示器坐标包含虚拟屏幕原点。
- 宿主剪贴板能力新增图片写入，截图插件不再直接调用系统剪贴板。
- 截图的全屏与区域热键独立注册并支持备用组合，单个冲突不会阻断插件启动。
- 文件夹备注命令真正消费 Explorer 选区中的文件夹路径，并在热键冲突时保留命令中心入口。
- 窗口管理提供 12 个可搜索命令、11 个可选快捷键和统一 Long 帮助窗口；局部热键冲突不会影响其他布局能力。
- 示例插件展示 `IPluginCommandHandler`、结构化调用、标准结果与清单声明，成为新的原生插件开发参考。
- 7 个原生插件的构建复制不再依赖 `SolutionDir`，支持解决方案和项目级独立构建。
- 当批 69 项自动化测试全部通过；当前主线 188 项全部通过，运行冒烟加载 20 / 20 个插件。
