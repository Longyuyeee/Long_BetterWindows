# Long窗口·全能助手 — 插件开发指南

## 1. 快速开始

### 环境要求
- .NET 8.0 SDK
- Windows 10/11
- 任意代码编辑器 (推荐 VS Code / Rider / Visual Studio)

### 5 分钟创建第一个插件

```powershell
# 1. 使用脚手架创建
.\new-plugin.ps1 -Name "我的插件" -Id "com.example.myplugin" -Template hotkey

# 2. 构建
dotnet build

# 3. 启动宿主
dotnet run --project src/LongBetterWindows.Host

# 插件自动出现在 ToolCenter → 插件 列表中
```

## 2. 项目结构

```
/Plugins/[PluginID]/
  ├── manifest.json        # 插件清单（必填）
  ├── plugin.dll           # 编译输出（自动）
  ├── config.json          # 用户配置（自动生成，持久化）
  ├── /assets              # 静态资源（可选）图标等
  └── /ui                  # UI 布局（可选，通过 IHasSettingsUI）
```

## 3. manifest.json 规范

```json
{
  "id": "com.example.myplugin",          // 唯一标识，反向域名格式
  "version": "1.0.0",                    // 语义化版本
  "name": "我的插件",                     // 显示名称
  "author": "作者名",                     // 作者
  "entry_point": "MyPlugin.dll",         // 入口 DLL 文件名

  "capabilities": [                      // 需要的能力（权限声明）
    "system.hotkey",
    "shell.selection",
    "fs.ads.access",
    "system.registry.write",
    "system.registry.read",
    "storage.local"
  ],

  "default_settings": {                  // 默认配置（可选）
    "hotkey": "Alt+X",
    "auto_start": true
  }
}
```

### 可用能力列表

| 能力 ID | 说明 | 接口 |
|---|---|---|
| `system.hotkey` | 全局热键注册 | `IHotKeyService` |
| `shell.selection` | 资源管理器选中项感知 | `IShellSelectionService` |
| `shell.context_menu` | 右键菜单注册 | `ContextMenuService` |
| `shell.ui.locator` | 文件坐标获取 | `IShellSelectionService` |
| `fs.ads.access` | NTFS 备用数据流读写 | `IADSService` |
| `system.registry.write` | 注册表写入 | `IRegistryService` |
| `system.registry.read` | 注册表读取 | `IRegistryService` |
| `storage.local` | 本地 KV 存储 | `IStorageService` |

## 4. 核心接口

### ILongPlugin — 插件生命周期

```csharp
public interface ILongPlugin
{
    string Id { get; }            // 与 manifest 一致
    string Name { get; }          // 显示名称
    string Version { get; }       // 版本号
    PluginState State { get; }    // 当前状态

    Task<bool> InitializeAsync(IHostApi host);  // 初始化，获取能力
    Task<bool> StartAsync();                    // 启动，注册热键等
    Task<bool> StopAsync();                     // 停止，释放资源
}
```

**生命周期流程：**
```
Loaded → InitializeAsync → StartAsync → Running
                                          ↓
                           StopAsync → Disabled
```

### IHostApi — 宿主能力入口

```csharp
public interface IHostApi
{
    IHotKeyService? HotKey { get; }                // 热键服务
    IShellSelectionService? ShellSelection { get; } // Explorer 感知
    IADSService? ADS { get; }                      // NTFS ADS 存储
    IRegistryService? Registry { get; }            // 注册表操作
    IStorageService? Storage { get; }              // 本地 KV 存储
}
```

> **注意：** 只有在 manifest.capabilities 中声明的能力才会返回非 null 实例。
> 未声明的能力返回 null。

### IHasSettingsUI — 自定义设置面板（可选）

```csharp
public interface IHasSettingsUI
{
    FrameworkElement CreateSettingsUI();  // 返回 WPF 面板
}
```

实现此接口后，ToolCenter 插件卡会出现齿轮 ⚙ 按钮，点击弹出设置窗口。

## 5. 三种插件模板

### Level 1: empty-plugin（最小骨架）

仅实现生命周期，不使用任何能力。适合纯后台插件。

```csharp
public class MyPlugin : ILongPlugin
{
    public string Id => "com.example.myplugin";
    public string Name => "我的插件";
    public string Version => "1.0.0";
    public PluginState State { get; private set; } = PluginState.Loaded;

    public Task<bool> InitializeAsync(IHostApi host) { return Task.FromResult(true); }
    public Task<bool> StartAsync() { State = PluginState.Running; return Task.FromResult(true); }
    public Task<bool> StopAsync() { State = PluginState.Disabled; return Task.FromResult(true); }
}
```

### Level 2: hotkey-plugin（热键插件）

注册全局热键，触发时执行自定义逻辑。

```csharp
public Task<bool> InitializeAsync(IHostApi host)
{
    _host = host;
    if (host.HotKey == null) return Task.FromResult(false); // 能力未授权
    return Task.FromResult(true);
}

public async Task<bool> StartAsync()
{
    var result = await _host.HotKey.RegisterAsync("Alt+X", OnTriggered);
    if (!result.IsSuccess) return false;
    State = PluginState.Running;
    return true;
}

private void OnTriggered()
{
    // 你的热键逻辑
    Application.Current.Dispatcher.Invoke(() =>
    {
        MessageBox.Show("热键触发！");
    });
}
```

### Level 3: full-plugin（全功能插件）

多能力 + 自定义设置 UI + 配置持久化。

```csharp
public class FullPlugin : ILongPlugin, IHasSettingsUI
{
    // ... 生命周期实现 ...

    public FrameworkElement CreateSettingsUI()
    {
        // 返回自定义设置面板
        var panel = new StackPanel();
        panel.Children.Add(new TextBlock { Text = "插件设置" });
        // ... 更多控件
        return panel;
    }
}
```

## 6. 常用模式

### 模式 A：热键 + Shell 感知
```
插件注册热键 → 热键触发 → 调用 ShellSelection 获取选中文件
→ 执行业务逻辑（如备注、重命名、分类）
```

### 模式 B：后台服务
```
插件启动 → 注册多个热键 → 长期监听 → 热键触发各自功能
```

### 模式 C：存储型
```
插件启动 → 读取 Storage 配置 → 根据配置执行 → 保存到 Storage
```

### 模式 D：窗口型
```
热键/菜单触发 → 弹出 WPF 窗口 → 用户交互 → 调用宿主能力保存
```

## 7. 调试技巧

1. **查看日志：** `logs/log.txt` 包含所有插件加载和运行日志
2. **热重载：** 修改插件 DLL 后，宿主自动检测并重载
3. **PluginState：** 插件状态异常时检查 Error 状态
4. **能力检查：** 始终验证 `host.XXX != null` 再使用

## 8. 发布插件

```
MyPlugin/
├── MyPlugin.dll          # 编译输出
├── manifest.json         # 插件清单
└── config.json           # 默认配置（可选）

打包为 .zip → 用户解压到 Plugins/ 目录 → 重启宿主即可加载
```

## 10. API 速查

### IHotKeyService
```csharp
Task<HostApiResponse> RegisterAsync(string hotkey, Action callback);
Task<HostApiResponse> UnregisterAsync(string hotkey);
Task<HostApiResponse<bool>> IsConflictAsync(string hotkey);
// hotkey 格式: "Ctrl+K" "Alt+M" "Win+N" "Ctrl+Shift+Space" "F6"
```

### IShellSelectionService
```csharp
Task<HostApiResponse<string>> GetActiveExplorerFolderPathAsync();
Task<HostApiResponse<List<string>>> GetSelectedItemsAsync();
Task<HostApiResponse<ScreenRect>> GetSelectedItemScreenRectAsync();
```

### IADSService
```csharp
Task<HostApiResponse<string>> ReadAsync(string filePath, string streamName);
Task<HostApiResponse> WriteAsync(string filePath, string streamName, string content);
Task<HostApiResponse> DeleteAsync(string filePath, string streamName);
Task<HostApiResponse<bool>> ExistsAsync(string filePath, string streamName);
```

### IStorageService
```csharp
Task<HostApiResponse<string?>> GetAsync(string key);
Task<HostApiResponse> SetAsync(string key, string value);
Task<HostApiResponse> DeleteAsync(string key);
Task<HostApiResponse<bool>> ContainsKeyAsync(string key);
```

### IRegistryService
```csharp
Task<HostApiResponse<string?>> ReadValueAsync(string key, string valueName);
Task<HostApiResponse> WriteValueAsync(string key, string valueName, string value);
Task<HostApiResponse> DeleteValueAsync(string key, string valueName);
Task<HostApiResponse> RollbackAsync(string pluginId);
```
