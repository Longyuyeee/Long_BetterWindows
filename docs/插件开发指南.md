# Long窗口·全能助手 — 插件开发指南

---

## 开发规则 (Development Rules)

> **以下规则适用于本项目所有插件开发，包括我们自己。**

1. **能力驱动** — 插件不直接访问系统资源，必须通过 `IHostApi` / `long.*` 调用宿主能力
2. **三种运行时同等对待** — HTML/JS、C# 脚本(.csx)、DLL 三种方式共享同一套能力 API
3. **API 新增先于插件** — 开发新插件前，先评估是否需要新增原子能力；如果需要，先补全能力接口再开发插件
4. **manifest 是入口** — 所有插件必须有 `manifest.json`，能力声明即权限
5. **文档同步更新** — 新增能力或 API 时，必须同步更新本文档

---

## 1. 选择你的开发方式

| | HTML/JS 插件 | C# 脚本 (.csx) | DLL 插件 |
|---|---|---|---|
| **语言** | HTML + CSS + JavaScript | C# | C# (.NET) |
| **入门门槛** | ⭐ 最低 | ⭐⭐ 中等 | ⭐⭐⭐ 较高 |
| **编译** | 不需要 | 不需要 | `dotnet build` |
| **生效速度** | 保存即生效 | 保存即生效 | 分钟级 |
| **UI 能力** | HTML/CSS 完整渲染 | 无内置 UI | WPF 原生 |
| **适用场景** | 富 UI 工具、面板 | 快速自动化脚本 | 性能敏感、系统级 |
| **上手时间** | 1 分钟 | 5 分钟 | 15 分钟 |

### 推荐：新手从 HTML/JS 开始，需要复杂逻辑或原生性能时升级到 DLL。

## 2. 5 分钟创建第一个插件

### HTML/JS 插件（最快）

```powershell
# 1. 创建目录
mkdir src/MyPlugin

# 2. 创建 index.html + manifest.json
# （内容见下方示例）

# 3. 构建并启动
dotnet build && dotnet run --project src/LongBetterWindows.Host

# 插件自动出现在 ToolCenter 插件列表中
```

### C# 脚本插件
```powershell
.\new-plugin.ps1 -Name "我的脚本" -Id "com.example.script" -Template script
# 编辑 plugin.csx → 保存即生效
```

### DLL 插件
```powershell
.\new-plugin.ps1 -Name "我的插件" -Id "com.example.mine" -Template hotkey
dotnet build
# DLL 自动复制到 Plugins/ → PluginScanner 加载
```

## 3. manifest.json 规范

```json
{
  "id": "com.example.myplugin",          // ★ 必填，反向域名格式，全局唯一
  "version": "1.0.0",                    // ★ 必填，语义化版本 x.y.z
  "name": "我的插件",                     // ★ 必填，显示名称
  "author": "作者名",                     // 作者
  "entry_point": "index.html",           // ★ 必填，入口文件名

  "runtime": "webview",                  // 可选: null(默认=DLL) | "csharp-script" | "webview"

  "capabilities": [                      // ★ 能力声明 = 权限
    "system.hotkey",
    "system.clipboard",
    "shell.selection",
    "fs.ads.access",
    "system.registry.write",
    "storage.local"
  ],

  "lifecycle": {                         // 可选；省略时采用安全兼容默认值
    "start_with_host": true,             // 是否随宿主启动
    "close_behavior": "background",     // "stop" | "background"
    "default_presentation": "detached", // "embedded" | "detached"
    "search_in_background": false        // 后台时是否继续提供动态搜索
  },

  "default_settings": {
    "hotkey": "Alt+X",
    "auto_start": true
  }
}
```

### lifecycle 字段说明

宿主使用统一状态机管理插件：`Loaded → Running → Background → Stopped`，任一运行阶段均可进入 `Error`。旧插件无需修改；历史 `Disabled` 状态会按 `Stopped` 处理，原有 `default_settings.auto_start` 仍作为用户配置兼容入口。

只有同时声明 `close_behavior: "background"` 和 `search_in_background: true` 的插件，转入后台后才会继续向统一搜索提供动态结果。需要在后台挂起或恢复自身资源的 DLL 插件可选实现 `IPluginBackgroundLifecycle`。

停止时宿主会统一注销当前插件通过 `IHotKeyService` 注册的热键。插件仍应在 `StopAsync()` 停止工作；需要额外释放事件订阅、计时器或原生句柄时，可选实现 `IPluginResourceLifecycle.ReleaseResourcesAsync()`。该方法可能在停止、热重载或宿主退出时调用，因此必须支持安全重复执行。Web 插件的宿主窗口关闭会自动按 `close_behavior` 转入后台或停止，停止时由宿主销毁 WebView2。

Web 插件的 `default_presentation: "embedded"` 会在管理中心内容区承载界面，`"detached"` 使用独立插件窗口。嵌入界面可以无重载切换到分离窗口；两种模式的返回、关闭和 Esc 都按 `close_behavior` 执行，单纯“分离窗口”不会触发停止或后台转换。窗口关闭只影响当前运行状态，不会把用户的 `auto_start` 偏好改为 false。

### localization 字段说明

插件可以选择声明语言资源。未声明 `localization` 的旧插件继续使用 Manifest 和界面中的原文，宿主不会发送语言通知，也不会改变其启停行为。

```json
{
  "localization": {
    "default_language": "zh-CN",
    "resources": {
      "zh-CN": "i18n/zh-CN.json",
      "en-US": "i18n/en-US.json"
    }
  }
}
```

资源文件是扁平 JSON 字符串字典，由插件自行定义稳定键：

```json
{
  "plugin.name": "示例插件",
  "action.run": "运行",
  "status.empty": "暂无内容"
}
```

`default_language` 必须存在于 `resources`。每个路径必须是插件目录内的 `.json` 相对路径，不允许绝对路径或 `..`；最多声明 16 种语言。单个资源文件不得超过 256 KiB、512 个键，键最长 128 字符，值最长 4096 字符。当前宿主语言没有对应资源时回退到插件默认语言。资源在通知前复制为只读上下文，插件不能修改宿主持有的快照。

DLL 插件可选实现 `IPluginLanguageLifecycle`：

```csharp
public Task OnLanguageChangedAsync(
    PluginLanguageContext context,
    CancellationToken cancellationToken = default)
{
    Title = context.Resources["plugin.name"];
    return Task.CompletedTask;
}
```

C# 脚本可设置 `LanguageChanged` 委托：

```csharp
LanguageChanged = context =>
{
    var title = context.Resources["plugin.name"];
    return Task.CompletedTask;
};
```

Web 插件通过现有 WebView 消息桥接收最新语言快照：

```js
window.chrome.webview.addEventListener('message', ({ data }) => {
  if (data?.type !== 'long.language-changed') return;
  document.documentElement.lang = data.resolved_language;
  document.title = data.resources['plugin.name'];
});
```

消息包含 `requested_language`、实际回退后的 `resolved_language` 和 `resources`。宿主只保留最新快照，并在页面导航完成后投递或重放；切换语言不会重建 WebView、重启插件、清空状态或绕过生命周期。语言回调失败只写日志，不会自动把插件切换为 `Error`。

完整样板见 `src/Base64Tool`（Web）和 `src/FolderNotePlugin`（DLL）。两者同时使用 `plugin.name`、`commands.{commandId}.title`、`commands.{commandId}.description` 供宿主投影插件名称和命令元数据；插件内部 UI 继续在同一字典中定义自己的稳定键。宿主投影不会修改原始 Manifest、命令对象或命令目录修订。

### 命令参数 Schema 与预设

插件命令可以通过 `argument_schema` 声明结构化参数。宿主会用同一份契约生成组合动作编辑器、校验 Manifest 默认值与静态预设，并在普通命令、工作流预检、动态绑定解析和补偿执行前再次校验。未声明 Schema 的旧命令保持兼容，继续使用自由键值参数。

```json
{
  "id": "generate",
  "title": "生成内容",
  "accepted_inputs": ["none"],
  "argument_schema": [
    {
      "key": "prompt",
      "name": "提示词",
      "description": "用于生成内容的文本",
      "type": "string",
      "required": true,
      "min_length": 1,
      "max_length": 2000
    },
    {
      "key": "amount",
      "name": "生成数量",
      "type": "integer",
      "default_value": "10",
      "minimum": 1,
      "maximum": 100
    },
    {
      "key": "temperature",
      "name": "随机度",
      "type": "number",
      "default_value": "0.7",
      "minimum": 0,
      "maximum": 1
    },
    {
      "key": "compact",
      "name": "紧凑输出",
      "type": "boolean",
      "default_value": "false"
    },
    {
      "key": "format",
      "name": "输出格式",
      "type": "enum",
      "default_value": "plain",
      "enum_values": ["plain", "markdown", "json"]
    },
    {
      "key": "token",
      "name": "访问令牌",
      "description": "仅在本次工作流配置中使用",
      "type": "string",
      "sensitive": true,
      "max_length": 4096
    }
  ],
  "argument_presets": [
    {
      "id": "quick",
      "name": "快速模式",
      "arguments": {
        "prompt": "生成摘要",
        "amount": "10",
        "temperature": "0.7",
        "compact": "true",
        "format": "plain"
      }
    }
  ]
}
```

支持的参数类型与控件如下：

| `type` | 编辑器 | 可用约束 |
|---|---|---|
| `string` | 文本框；`sensitive: true` 时为密码框 | `min_length`、`max_length` |
| `integer` | 数值文本框 | `minimum`、`maximum`，边界必须为整数 |
| `number` | 数值文本框 | `minimum`、`maximum` |
| `boolean` | 复选框 | 无 |
| `enum` | 下拉框 | 必须声明 1–64 个唯一 `enum_values` |

`key` 是插件实现读取的稳定机器标识，升级时不要随意修改；`name` 和 `description` 面向用户，可以本地化。`required` 表示执行时必须有值；`default_value` 必须使用字符串表示并满足同一类型与约束。未填写的可选参数如果声明了默认值，宿主会在执行前补齐并规范化，例如整数 `"0010"` 变为 `"10"`、布尔 `"TRUE"` 变为 `"true"`。

预设只属于声明它的命令，应用时会完整替换当前参数字典。每条命令最多声明 64 个 Schema 参数和 32 个预设，每个预设最多 64 个参数；预设 ID 与参数 key 必须在各自命令内唯一。声明 Schema 后，预设不能包含未知 key，且所有值都必须通过 Schema 校验。

不要在 Manifest 的默认值或预设中放置令牌、密码或用户数据。`sensitive` 负责编辑器遮罩和错误信息防泄漏，不代表自动获得安全存储；宿主仍把进入工作流的全部参数视为潜在敏感持久化输入，保存前要求用户明确批准。

Web 插件通过命令回调读取规范化后的字符串值：

```js
window.LongUI?.onCommand(function (command) {
  if (command.command_id !== 'generate') {
    return { success: false, message: '未知命令', outputs: {} };
  }

  const args = command.arguments || {};
  const amount = Number.parseInt(args.amount, 10);
  const compact = args.compact === 'true';
  const format = args.format;
  // 执行业务逻辑，并返回声明过的 outputs。
});
```

实际内置样板见 `src/UuidGenerator/manifest.json`：`amount` 使用 1–100 的整数约束，`uppercase` 与 `compact` 使用布尔参数，三个历史预设均通过同一 Schema 校验。

### runtime 字段说明

| runtime 值 | 入口文件 | 加载方式 |
|---|---|---|
| (省略/空) | `.dll` 文件 | AssemblyLoadContext 隔离加载 |
| `"csharp-script"` | `.csx` 文件 | Roslyn CSharpScript 直接执行 |
| `"webview"` | `.html` 文件 | WebView2 渲染 + `long.*` JS API |

### 可用能力 (Capabilities) — 完整 14 项

| 能力 ID | 说明 | C# 接口 | JS API |
|---|---|---|---|
| `system.hotkey` | 全局热键注册/注销/冲突/更换 | `IHotKeyService` | `long.hotkey.*` |
| `system.clipboard` | 剪贴板读写/清空 | `IClipboardService` | `long.clipboard.*` |
| `system.notification` | 原生 Windows Toast + 浮窗回退 | `INotificationService` | `long.app.showNotification` |
| `system.screenshot` | 全屏/区域截图 | `IScreenCaptureService` | `long.screenshot.*` |
| `system.input` | 模拟按键/鼠标点击/移动 | `IInputService` | — |
| `system.process` | 进程启动/列表/终止 | `IProcessService` | — |
| `system.registry.read` | 注册表读取 | `IRegistryService` | `long.registry.*` |
| `system.registry.write` | 注册表写入(含回滚) | `IRegistryService` | `long.registry.*` |
| `shell.selection` | Explorer 选中项/文件夹/坐标 | `IShellSelectionService` | `long.shell.get*` |
| `shell.execute` | 打开 URL/文件夹/文件 | `IShellExecuteService` | `long.shell.open*` |
| `fs.ads.access` | NTFS 备用数据流读写/删除 | `IADSService` | `long.fs.ads.*` |
| `file.ops` | 文件复制/移动/删除/存在 | `IFileOpsService` | `long.shell.renameFile` |
| `window.info` | 前台窗口信息/可见窗口列表 | `IWindowInfoService` | `long.window.*` |
| `storage.local` | 本地 KV 持久化存储 | `IStorageService` | `long.storage.*` |
| `network.http` | HTTP GET/POST/下载 | `IHttpService` | `long.http.*` |

> **宿主 API 权限边界**：插件通过 `IHostApi` / `long.*` 使用的能力必须在 `capabilities` 中声明，未声明时会抛出 `UnauthorizedAccessException`。Web 插件还受本地页面来源校验；DLL 与 C# 脚本仍可直接调用 .NET、P/Invoke 和文件系统，因此属于完全信任代码，不应把 Manifest 能力声明理解为进程级沙盒。
> 使用 `host.HasCapability("能力ID")` 可在初始化时检查权限。
> 权限拒绝后检查 `host.LastAccessError` 可获取详细错误信息。

### 权限诊断示例
```csharp
public Task<bool> InitializeAsync(IHostApi host)
{
    // 可选：提前检查并给出友好提示
    if (!host.HasCapability("network.http"))
    {
        Log.Error("本插件需要 network.http 能力，请在 manifest.json 中添加");
        return Task.FromResult(false);
    }
    // 或者直接访问（无权限会抛出 UnauthorizedAccessException）
    var http = host.Http;
    return Task.FromResult(true);
}
```


```json
// manifest.json
{
  "id": "com.example.quick",
  "name": "快速工具",
  "entry_point": "index.html",
  "runtime": "webview",
```

### 4B. C# 脚本插件 (runtime: "csharp-script")

```csharp
// plugin.csx — 保存即生效！
// 脚本中可直接使用 Host (IHostApi) 和 Id, Name 变量
// 如果 manifest 中未声明相应能力，Host.HotKey 等访问会抛出异常
Start = async () =>
{
    await Host.HotKey.RegisterAsync("Alt+X", async () =>
    {
        var t = await Host.Clipboard.GetTextAsync();
        if (t.IsSuccess && t.Data != null)
            await Host.Storage.SetAsync("last_clip", t.Data);
    });
};

Stop = async () =>
{
    await Host.HotKey.UnregisterAsync("Alt+X");
};
```

### 4C. DLL 插件 (默认)

```csharp
public class MyPlugin : ILongPlugin
{
    private IHostApi _host = null!;
    private IHotKeyService _hotKey = null!;

    public string Id => "com.example.myplugin";
    public string Name => "我的插件";
    public string Version => "1.0.0";
    public PluginState State { get; private set; } = PluginState.Loaded;

    public Task<bool> InitializeAsync(IHostApi host)
    {
        _host = host;
        _hotKey = host.HotKey;  // 若 manifest 未声明 system.hotkey 会抛出 UnauthorizedAccessException
        return Task.FromResult(true);
    }

    public async Task<bool> StartAsync()
    {
        var ok = await _hotKey.RegisterAsync("Alt+X", OnHotkey);
        if (ok.IsSuccess) State = PluginState.Running;
        return ok.IsSuccess;
    }

    public async Task<bool> StopAsync()
    {
        await _hotKey.UnregisterAsync("Alt+X");
        State = PluginState.Stopped;
        return true;
    }

    private void OnHotkey()
    {
        // 热键触发时的逻辑
    }
}

// 可选：自定义设置面板
public class MyPlugin : ILongPlugin, IHasSettingsUI
{
    public FrameworkElement CreateSettingsUI() { /* 返回 WPF 面板 */ }
}

// 可选：插件有独立窗口
public class MyPlugin : ILongPlugin, IHasMainUI
{
    public void ShowMainUI() { /* 打开插件主窗口 */ }
}
```

## 5. JS API 完整参考 (runtime: webview)

所有 JS API 返回 `Promise<{success: boolean, data?: any, error?: string}>`

### long.app

```js
await long.app.openUrl('https://github.com')       // 浏览器打开链接
await long.app.openFolder('C:\\Users')              // 资源管理器打开文件夹
await long.app.openWithDefault('file.txt')          // 默认程序打开文件
await long.app.showNotification('标题', '内容')      // 原生 Windows Toast（系统托盘气泡）+ 浮窗回退
await long.app.getVersion()                         // {version: "0.2.0"}
```

### long.clipboard

```js
let r = await long.clipboard.getText()         // {success, data: string}
await long.clipboard.setText('hello')           // {success}
await long.clipboard.clear()                    // {success}
let monitor = await long.clipboard.startMonitoring(function (event) {
  // event: {type: 'clipboard.changed', content_type, text, timestamp}
  if (event.content_type === 'text') console.log(event.text)
})                                               // {success}
await long.clipboard.stopMonitoring()            // {success}
```

`startMonitoring` 需要声明 `system.clipboard.monitor`。每次成功启动都由当前 Web
运行时持有一份监听租约；同一运行时重复启动是幂等的，卸载时会自动释放。主动停止后不得继续依赖旧回调。宿主只在最后一个消费者释放后移除 Windows 剪贴板监听，因此插件不能用自己的停止操作影响其他插件。

### long.shell

```js
let r = await long.shell.getActiveFolder()      // {success, data: {path}}
let r = await long.shell.getSelectedItems()     // {success, data: [path, ...]}
let r = await long.shell.getItemScreenRect()    // {success, data: {x, y, w, h}}
```

### long.fs.ads

```js
let r = await long.fs.ads.read('/path', 'mystream')           // {success, data: string}
await long.fs.ads.write('/path', 'content', 'mystream')       // {success}
await long.fs.ads.delete('/path', 'mystream')                 // {success}
let r = await long.fs.ads.exists('/path', 'mystream')         // {success, data: bool}
let r = await long.fs.ads.isNTFS('/path')                    // {success, data: bool}
```

### long.hotkey

```js
await long.hotkey.register('Alt+X')              // {success}
await long.hotkey.unregister('Alt+X')            // {success}
let r = await long.hotkey.isConflict('Alt+X')    // {success, data: bool}
// 热键触发时通过 message 事件通知: {type: 'hotkey', hotkey: 'Alt+X'}
```

### long.registry

```js
let r = await long.registry.read('Software\\MyKey', 'ValueName')    // {success, data: string}
await long.registry.write('Software\\MyKey', 'ValueName', 'value')  // {success}
await long.registry.delete('Software\\MyKey', 'ValueName')          // {success}
```

### long.storage

```js
let r = await long.storage.get('key')             // {success, data: string}
await long.storage.set('key', 'value')            // {success}
await long.storage.delete('key')                  // {success}
let r = await long.storage.containsKey('key')     // {success, data: bool}
```

### long.ui

```js
await long.ui.showToast('操作成功')                 // 浮窗 Toast（始终可用，无能力要求）
```

### long.window

```js
let r = await long.window.getForeground()            // {title, processName, x, y, width, height, isTopmost}
```

### long.shell (扩展 — shell.execute 能力)

```js
await long.shell.openUrl('https://github.com')       // 浏览器打开链接
```

### long.http (network.http 能力)


## 9. 安全边界与分发策略

- Web 插件的顶层页面只能导航到自身插件目录中的 `file:` 页面；`http:`、`https:`、`data:`、`about:`、目录穿越及相似前缀目录都会被拒绝。
- `long.*` Bridge 只接收来自插件自身目录页面的消息。远程 iframe 即使尝试发送消息，也无法调用宿主能力。
- `window.open()` 和 WebView2 浏览器下载默认被阻止。打开外部链接应声明 `shell.execute` 并调用 `long.app.openUrl()`；下载应声明 `network.http` 并调用 `long.http.download()`。
- 正式构建默认关闭 WebView2 DevTools。调试 Web 插件请使用独立浏览器和 Mock API，或使用 Debug 构建与宿主日志。
- 远程插件市场当前只接受经过可信发布者签名的 `webview` 插件。DLL 与 `csharp-script` 只能本地导入，安装时必须向用户展示完全信任警告。
