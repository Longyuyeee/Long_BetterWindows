# Long窗口·全能助手 — 插件开发指南

---

## 开发规则 (Development Rules)

> **以下规则适用于本项目所有插件开发，包括我们自己。**

1. **能力驱动** — 插件不直接访问系统资源，必须通过 `IHostApi` / `long.*` 调用宿主能力
2. **三种运行时同等对待** — HTML/JS、C# 脚本(.csx)、DLL 三种方式共享同一套能力 API
3. **API 新增先于插件** — 开发新插件前，先评估是否需要新增原子能力；如果需要，先补全能力接口再开发插件
4. **manifest 是入口** — 所有插件必须有 `manifest.json`，能力声明即权限
5. **文档同步更新** — 新增能力或 API 时，必须同步更新本文档

---

## 1. 选择你的开发方式

| | HTML/JS 插件 | C# 脚本 (.csx) | DLL 插件 |
|---|---|---|---|
| **语言** | HTML + CSS + JavaScript | C# | C# (.NET) |
| **入门门槛** | ⭐ 最低 | ⭐⭐ 中等 | ⭐⭐⭐ 较高 |
| **编译** | 不需要 | 不需要 | `dotnet build` |
| **生效速度** | 保存即生效 | 保存即生效 | 分钟级 |
| **UI 能力** | HTML/CSS 完整渲染 | 无内置 UI | WPF 原生 |
| **适用场景** | 富 UI 工具、面板 | 快速自动化脚本 | 性能敏感、系统级 |
| **上手时间** | 1 分钟 | 5 分钟 | 15 分钟 |

### 推荐：新手从 HTML/JS 开始，需要复杂逻辑或原生性能时升级到 DLL。

## 2. 5 分钟创建第一个插件

### HTML/JS 插件（最快）

```powershell
# 1. 创建目录
mkdir src/MyPlugin

# 2. 创建 index.html + manifest.json
# （内容见下方示例）

# 3. 构建并启动
dotnet build && dotnet run --project src/LongBetterWindows.Host

# 插件自动出现在 ToolCenter 插件列表中
```

### C# 脚本插件
```powershell
.\new-plugin.ps1 -Name "我的脚本" -Id "com.example.script" -Template script
# 编辑 plugin.csx → 保存即生效
```

### DLL 插件
```powershell
.\new-plugin.ps1 -Name "我的插件" -Id "com.example.mine" -Template hotkey
dotnet build
# DLL 自动复制到 Plugins/ → PluginScanner 加载
```

## 3. manifest.json 规范

```json
{
  "id": "com.example.myplugin",          // ★ 必填，反向域名格式，全局唯一
  "version": "1.0.0",                    // ★ 必填，语义化版本 x.y.z
  "name": "我的插件",                     // ★ 必填，显示名称
  "author": "作者名",                     // 作者
  "entry_point": "index.html",           // ★ 必填，入口文件名

  "runtime": "webview",                  // 可选: null(默认=DLL) | "csharp-script" | "webview"

  "capabilities": [                      // ★ 能力声明 = 权限
    "system.hotkey",
    "system.clipboard",
    "shell.selection",
    "fs.ads.access",
    "system.registry.write",
    "storage.local"
  ],

  "default_settings": {
    "hotkey": "Alt+X",
    "auto_start": true
  }
}
```

### runtime 字段说明

| runtime 值 | 入口文件 | 加载方式 |
|---|---|---|
| (省略/空) | `.dll` 文件 | AssemblyLoadContext 隔离加载 |
| `"csharp-script"` | `.csx` 文件 | Roslyn CSharpScript 直接执行 |
| `"webview"` | `.html` 文件 | WebView2 渲染 + `long.*` JS API |

### 可用能力 (Capabilities)

| 能力 ID | 说明 | C# 接口 | JS API |
|---|---|---|---|
| `system.hotkey` | 全局热键 | `IHotKeyService` | `long.hotkey.*` |
| `system.clipboard` | 剪贴板读写 | `IClipboardService` | `long.clipboard.*` |
| `shell.selection` | Explorer 感知 | `IShellSelectionService` | `long.shell.*` |
| `fs.ads.access` | NTFS ADS 存储 | `IADSService` | `long.fs.ads.*` |
| `system.registry.write` | 注册表写入 | `IRegistryService` | `long.registry.*` |
| `system.registry.read` | 注册表读取 | `IRegistryService` | `long.registry.*` |
| `storage.local` | 本地 KV 存储 | `IStorageService` | `long.storage.*` |

## 4. 三种运行时详细指南

### 4A. HTML/JS 插件 (runtime: "webview")

**最小示例——1 个 HTML 文件就是一个插件：**

```html
<!-- src/MyPlugin/index.html -->
<!DOCTYPE html>
<html>
<head><meta charset="UTF-8"><title>我的插件</title></head>
<body>
  <button onclick="go()">执行</button>
  <script>
    async function go() {
      let folder = await long.shell.getActiveFolder();
      long.ui.showToast('当前: ' + folder.data);
    }
  </script>
</body>
</html>
```

```json
// manifest.json
{
  "id": "com.example.quick",
  "name": "快速工具",
  "entry_point": "index.html",
  "runtime": "webview",
  "capabilities": ["shell.selection"]
}
```

### 4B. C# 脚本插件 (runtime: "csharp-script")

```csharp
// plugin.csx — 保存即生效！
Start = async () =>
{
    var host = Host;  // IHostApi 全局变量
    if (host.HotKey != null)
    {
        await host.HotKey.RegisterAsync("Alt+X", () =>
        {
            var t = host.Clipboard?.GetTextAsync().Result;
            if (t?.IsSuccess == true)
                host.Storage?.SetAsync("last_clip", t.Data);
        });
    }
};

Stop = async () =>
{
    await Host.HotKey?.UnregisterAsync("Alt+X");
};
```

### 4C. DLL 插件 (默认)

```csharp
public class MyPlugin : ILongPlugin
{
    private IHostApi? _host;

    public string Id => "com.example.myplugin";
    public string Name => "我的插件";
    public string Version => "1.0.0";
    public PluginState State { get; private set; } = PluginState.Loaded;

    public Task<bool> InitializeAsync(IHostApi host)
    {
        _host = host;
        // 验证能力授权
        if (host.HotKey == null) return Task.FromResult(false);
        return Task.FromResult(true);
    }

    public async Task<bool> StartAsync()
    {
        var ok = await _host!.HotKey!.RegisterAsync("Alt+X", OnHotkey);
        if (ok.IsSuccess) State = PluginState.Running;
        return ok.IsSuccess;
    }

    public async Task<bool> StopAsync()
    {
        await _host!.HotKey!.UnregisterAsync("Alt+X");
        State = PluginState.Disabled;
        return true;
    }

    private void OnHotkey()
    {
        // 热键触发时的逻辑
    }
}

// 可选：自定义设置面板
public class MyPlugin : ILongPlugin, IHasSettingsUI
{
    public FrameworkElement CreateSettingsUI() { /* 返回 WPF 面板 */ }
}
```

## 5. JS API 完整参考 (runtime: webview)

所有 JS API 返回 `Promise<{success: boolean, data?: any, error?: string}>`

### long.app

```js
await long.app.showNotification('标题', '内容')
```

### long.clipboard

```js
let r = await long.clipboard.getText()         // {success, data: string}
await long.clipboard.setText('hello')           // {success}
await long.clipboard.clear()                    // {success}
```

### long.shell

```js
let r = await long.shell.getActiveFolder()      // {success, data: {path}}
let r = await long.shell.getSelectedItems()     // {success, data: [path, ...]}
let r = await long.shell.getItemScreenRect()    // {success, data: {x, y, w, h}}
```

### long.fs.ads

```js
let r = await long.fs.ads.read('/path', 'mystream')           // {success, data: string}
await long.fs.ads.write('/path', 'content', 'mystream')       // {success}
await long.fs.ads.delete('/path', 'mystream')                 // {success}
let r = await long.fs.ads.exists('/path', 'mystream')         // {success, data: bool}
let r = await long.fs.ads.isNTFS('/path')                    // {success, data: bool}
```

### long.hotkey

```js
await long.hotkey.register('Alt+X')              // {success}
await long.hotkey.unregister('Alt+X')            // {success}
let r = await long.hotkey.isConflict('Alt+X')    // {success, data: bool}
// 热键触发时通过 message 事件通知: {type: 'hotkey', hotkey: 'Alt+X'}
```

### long.registry

```js
let r = await long.registry.read('Software\\MyKey', 'ValueName')    // {success, data: string}
await long.registry.write('Software\\MyKey', 'ValueName', 'value')  // {success}
await long.registry.delete('Software\\MyKey', 'ValueName')          // {success}
```

### long.storage

```js
let r = await long.storage.get('key')             // {success, data: string}
await long.storage.set('key', 'value')            // {success}
await long.storage.delete('key')                  // {success}
let r = await long.storage.containsKey('key')     // {success, data: bool}
```

### long.ui

```js
await long.ui.showToast('操作成功')
```

## 6. C# API 参考 (DLL / .csx)

> 所有方法返回 `Task<HostApiResponse<T>>`。检查 `result.IsSuccess` 和 `result.Data`。

### IHotKeyService
```csharp
Task<HostApiResponse> RegisterAsync(string hotkey, Action callback);
Task<HostApiResponse> UnregisterAsync(string hotkey);
Task<HostApiResponse<bool>> IsConflictAsync(string hotkey);
// hotkey 格式: "Ctrl+K" "Alt+M" "Win+N" "Ctrl+Shift+Space" "F6" "F7"
```

### IClipboardService
```csharp
Task<HostApiResponse<string?>> GetTextAsync();
Task<HostApiResponse> SetTextAsync(string text);
Task<HostApiResponse> ClearAsync();
```

### IShellSelectionService
```csharp
Task<HostApiResponse<string>> GetActiveExplorerFolderPathAsync();
Task<HostApiResponse<List<string>>> GetSelectedItemsAsync();
Task<HostApiResponse<ScreenRect>> GetSelectedItemScreenRectAsync();
```

### IADSService
```csharp
Task<HostApiResponse<string>> ReadAsync(string filePath, string streamName);
Task<HostApiResponse> WriteAsync(string filePath, string streamName, string content);
Task<HostApiResponse> DeleteAsync(string filePath, string streamName);
Task<HostApiResponse<bool>> ExistsAsync(string filePath, string streamName);
Task<HostApiResponse<bool>> IsNTFSVolumeAsync(string filePath);
```

### IStorageService
```csharp
Task<HostApiResponse<string?>> GetAsync(string key);
Task<HostApiResponse> SetAsync(string key, string value);
Task<HostApiResponse> DeleteAsync(string key);
Task<HostApiResponse<bool>> ContainsKeyAsync(string key);
```

### IRegistryService
```csharp
Task<HostApiResponse<string?>> ReadValueAsync(string key, string valueName);
Task<HostApiResponse> WriteValueAsync(string key, string valueName, string value);
Task<HostApiResponse> DeleteValueAsync(string key, string valueName);
Task<HostApiResponse> RollbackAsync(string pluginId);
```

## 8. 开发模式

### 模式 A：HTML UI + 宿主能力
```
用户按热键/点击按钮 → WebView2 加载 HTML
→ JS 调用 long.shell.getActiveFolder()
→ JS 调用 long.fs.ads.write()
→ 显示结果
```

### 模式 B：纯热键 + 后台处理
```
插件注册热键 → 热键触发 → C# 处理逻辑 → 读写能力服务
```

### 模式 C：脚本自动化
```
.csx 文件保存 → 热重载执行 → 注册热键/定时任务
```

### 模式 D：WPF 原生窗口
```
DLL 插件 → WPF Window → 调用宿主能力 → 显示结果
```
