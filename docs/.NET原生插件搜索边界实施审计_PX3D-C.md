## 本批结果

- Contracts SDK 新增 `IPluginSearchProvider`、`PluginSearchRequest`、`PluginSearchResult` 和声明式搜索动作。
- 公共查询合同不包含 `ContextSnapshot`；宿主只向插件传递查询、数量上限和去除插件前缀后的偏好 ID。
- 公共动作只允许执行本插件命令或继续搜索。宿主适配器负责命令归属检查、继续搜索长度限制、结果 ID 命名空间和内部模型映射。
- QuickLaunch 已迁移到公共合同并删除 Host 项目引用；Serilog 改为插件显式依赖，不再依赖 Host 的传递引用。
- `native-plugin-boundary-audit.json` 的 `host_coupled_projects` 已为空，八个原生生产组件全部进入 SDK-only 清单。
