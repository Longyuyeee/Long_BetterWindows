# Long 统一工作区交互细节审计与验收规范

> 审计日期：2026-07-28
>
> 依赖文档：[`uTools管理中心交互审计与统一工作区开发计划_2026-07-28.md`](uTools管理中心交互审计与统一工作区开发计划_2026-07-28.md)
>
> 适用范围：Launcher、管理中心、插件市场、插件设置、插件运行、分离窗口

## 1. 审计范围与证据等级

本轮不再讨论整体页面结构，重点审计用户完成任务时每一步会发生什么。

证据分为三类：

| 等级 | 来源 | 用途 |
|---|---|---|
| A | 用户截图与本机 uTools 实机观察 | 确认真实可见行为 |
| B | uTools 官方使用文档 | 补充点击、快捷键和生命周期规则 |
| C | Long 产品决策 | 将参考行为转换为 Long 自有交互契约 |

本轮实机确认：

- uTools Launcher 覆盖当前前台应用显示，是瞬态面板；
- 打开时输入框直接获得输入焦点；
- 空查询按“最近使用、已固定、当前前台应用动作、市场精选”分组；
- 右上角头像是稳定的管理入口；
- Launcher 失焦后立即收起，`Shift+Tab` 不进入常规页面 Tab 循环；
- 分离插件拥有独立窗口标题、插件图标、置顶、最小化、最大化和关闭控制；
- 本机密码管理器的锁定页在分离窗口中没有响应 `Esc`，说明插件内部状态可能先于通用退出规则处理按键。

本轮未把 uTools 的 UI Automation 暴露情况作为参考标准。其瞬态窗口未能稳定返回可读 UIA 树，但这不足以单独判断产品的辅助功能质量。

## 2. 核心交互原则

### 2.1 快速入口与持久工作区分开

Launcher 是瞬态入口：

- 唤起即聚焦；
- 失焦即隐藏；
- `Esc` 直接隐藏；
- 不承担长时间管理；
- 隐藏后归还原前台窗口焦点。

Workspace 是持久工作区：

- 失焦不关闭；
- 支持最小化、最大化和窗口恢复；
- `Esc` 按层级处理，不直接关闭整个窗口；
- 保存模块、选择、滚动和会话状态；
- 允许鼠标与完整键盘导航。

不得让一个窗口同时采用两套互相冲突的失焦规则。

### 2.2 导航动作与业务动作分开

以下属于导航：

- 打开管理中心；
- 打开市场；
- 选择插件；
- 打开插件设置；
- 返回上一个模块；
- 关闭当前模块。

以下属于业务动作：

- 运行插件；
- 停止插件；
- 安装、升级或卸载；
- 启用或禁用；
- 修改热键；
- 修改设置。

导航动作不得偷偷触发业务副作用。单击插件名称不能自动启动插件，关闭设置页也不能自动停止后台插件。

### 2.3 视图、模块和运行时分开

- **视图**：当前渲染的 WPF 或 WebView 内容。
- **模块**：可导航、可关闭、可恢复的工作区单元。
- **运行时**：插件后台服务、命令、监听器和状态。

关闭视图不等于关闭模块，关闭模块不等于结束运行，结束运行才释放插件运行时及其副作用。

## 3. Launcher 交互规范

### 3.1 唤起

| 条件 | 行为 |
|---|---|
| Launcher 未显示 | 在当前显示器居中或按最近位置显示 |
| Launcher 已显示 | 不创建第二个窗口，重新激活并聚焦输入框 |
| 当前有文本选择或 Explorer 选区 | 冻结为本次上下文快照 |
| 当前有旧查询 | 默认清空；从 Workspace 返回时可按返回意图恢复 |
| 当前前台窗口变化 | 本轮快照仍使用唤起瞬间的原窗口 |

首帧只绘制输入框、壳层和轻量骨架。上下文捕获与搜索 Provider 可增量返回，不应阻塞窗口出现。

### 3.2 空查询

空查询不是空白页，也不是普通搜索结果截断版。建议分区：

1. 最近使用；
2. 已固定；
3. 当前应用相关动作；
4. 推荐或市场精选；
5. 展开全部入口。

每一项显示真实图标、标题和必要的短说明。分区标题不可获得键盘焦点，分区中的项目进入同一上下选择序列。

当前 Long 差距：

- `CommandPaletteWindow` 对空查询仍调用统一搜索协调器；
- 最多只投影 12 条扁平结果；
- 结果模板没有真实应用/插件图标列；
- 没有头像或明确的管理中心入口；
- 来源以末尾文字呈现，信息层级偏技术化。

### 3.3 输入与结果

| 输入 | 行为 |
|---|---|
| 普通文字 | 全局搜索命令、插件、应用、文件和设置 |
| 粘贴文本 | 同时作为查询和候选命令文本输入 |
| 文件/图片上下文 | 显示可移除的上下文标记 |
| `↓` / `↑` | 在可执行结果间移动，不把焦点移出输入框 |
| `Enter` | 执行主动作 |
| `Shift+Enter` | 打开首个次级动作，后续可改为动作菜单 |
| `Ctrl+P` | 固定/取消固定当前结果 |
| `Esc` | 隐藏 Launcher 并归还焦点 |

搜索结果更新时：

- 尽量保持同一结果 ID 的选中状态；
- 原选中项消失时选择首个有效项；
- 旧请求必须取消且不能覆盖新请求；
- 错误 Provider 不阻塞其他 Provider；
- 状态栏不得朗读每一次中间批次，只朗读稳定结果或错误。

Long 已经具备查询取消、选中 ID 保持、上下选择、执行、固定、次级动作和失焦隐藏，应保留这些实现。

### 3.4 管理入口

Launcher 右上角放置 Long 品牌/个人入口。交互定义：

- 单击：打开 `management:root`；
- 在 Launcher 搜索“插件市场”并执行：打开 `management:root` 后激活 `marketplace:catalog`；
- 如果 Workspace 已打开：激活现有窗口和模块，不重复创建；
- 打开 Workspace 前保存 Launcher 查询、上下文与原前台窗口；
- Workspace 返回 Launcher 时按调用意图决定恢复或清空查询。

头像不能只承担账户含义。没有账户系统时仍应保留品牌入口，并通过工具提示和可访问名称明确“管理中心”。

## 4. Workspace Shell 交互规范

### 4.1 顶部模块条

模块条由根模块和子模块组成。

| 操作 | 行为 |
|---|---|
| 单击非活动模块 | 激活模块并恢复其视图状态 |
| 单击活动模块 | 不重建、不滚动到顶 |
| 单击子模块关闭按钮 | 请求关闭模块 |
| 关闭活动模块 | 激活最近一个仍有效的模块 |
| 关闭非活动模块 | 保持当前模块不变 |
| 再次打开同键模块 | 激活已有模块 |
| 模块有未提交状态 | 关闭前显示局部确认 |

根管理模块：

- 固定在第一位；
- 不显示关闭按钮；
- 标题为“管理中心”；
- 关闭整个 Workspace 窗口时只隐藏或按设置退出宿主。

子模块：

- 显示真实图标与短标题；
- 标题过长时省略，但工具提示显示全名；
- 关闭热区与标签主体分离；
- 关闭后焦点移到新活动模块标题或首个可操作控件。

第一阶段不实现拖拽排序、固定标签和跨窗口标签拖放，避免扩大状态机范围。

### 4.2 作用域搜索

模块条右侧输入框由活动模块声明：

| 活动模块 | 占位提示 | 搜索范围 |
|---|---|---|
| 管理中心 | 搜索设置、插件与管理功能 | 管理目的地 |
| 市场 | 搜索插件应用 | 远端/本地市场目录 |
| 插件设置 | 搜索插件设置 | 当前插件设置项，可选 |
| 插件运行 | 由插件声明 | 插件数据源 |
| 设置 | 搜索设置 | 宿主设置项 |

切换模块时：

- 每个模块保存自己的查询；
- 正在运行的旧查询立即取消；
- 新模块恢复自己的查询和结果；
- 输入法组合期间不触发提交动作；
- 清空按钮只清空当前作用域；
- `Ctrl+K` 聚焦作用域搜索；
- `Esc` 在输入有内容时先清空，输入为空时再执行模块返回。

市场内部不再保留第二个同级大搜索框。左侧插件目录的过滤框属于侧栏自身，不与顶部市场搜索共用文本。

### 4.3 左侧已安装插件目录

#### 单击和双击

| 操作 | 行为 |
|---|---|
| 单击插件行 | 选择插件并打开/激活 `plugin-settings:<id>` |
| 双击插件行 | 打开/激活插件运行模块 |
| 单击运行按钮 | 打开/激活插件运行模块 |
| 右键或更多菜单 | 显示运行、设置、启停、结束运行、卸载等动作 |
| `Enter` | 与单击相同，打开设置 |
| `Ctrl+Enter` | 运行插件 |
| `Delete` | 不直接卸载，只打开卸载确认 |

双击是效率增强，不是唯一运行方式。每个选中行必须有可发现的运行按钮或菜单动作。

#### 行内容

每行最多显示：

- 插件图标；
- 名称；
- 运行状态点；
- 更新标记；
- 必要的异常状态。

版本、运行时、热键、权限摘要等详细信息放在设置模块中，避免侧栏过密。

#### 目录状态

- 搜索过滤不改变当前模块；
- 当前插件被过滤掉时，详情模块保留但侧栏不显示选中高亮；
- 安装完成后增量插入并可选择新插件；
- 卸载完成后移除行，关闭对应设置和运行模块；
- 插件更新时不跳动滚动位置；
- 插件图标加载失败使用稳定占位图，不改变行高；
- 目录必须虚拟化。

### 4.4 底部固定入口

侧栏底部与插件滚动区分离，放置：

- 个人中心或本地身份入口；
- 全局设置；
- 必要的宿主状态入口。

插件列表滚动时底部入口保持固定。没有账号体系时不得显示虚假的登录状态。

## 5. 管理中心根模块

根模块不是介绍页，应优先提供高频状态与入口：

- 最近使用插件；
- 可用更新；
- 运行中的插件；
- 权限或错误提醒；
- 市场入口；
- 工作流、系统集成和设置入口。

点击卡片必须打开对应模块，不弹出第二套窗口。

避免：

- 大面积欢迎横幅；
- 重复说明产品功能；
- 与左侧目录重复的完整插件卡片墙；
- 每次进入都重新加载所有诊断与市场数据。

## 6. 市场模块

### 6.1 目录状态

市场至少包含：

- 加载骨架；
- 已加载目录；
- 搜索无结果；
- 离线缓存；
- 网络错误；
- 目录不可信或签名失败；
- 操作进行中；
- 可更新状态。

网络错误只影响市场数据，不影响本地插件目录、插件设置和运行模块。

### 6.2 选择与详情

宽布局：

- 单击结果选择项目并显示同模块详情；
- 再次单击不重置详情滚动；
- `Enter` 打开详情；
- `Esc` 从详情返回列表。

紧凑布局：

- 列表和详情是同一模块内的两级路由；
- `Enter`/单击进入详情；
- 返回按钮或 `Esc` 返回列表；
- 返回后恢复原选中项和滚动位置。

当前 Long 的 `MarketplaceControl` 已具备列表选择、紧凑布局进入详情、返回按钮和确认 Overlay，但这些状态仍在控件内部显隐，尚未进入统一模块路由。

### 6.3 安装、升级与卸载

流程固定为：

1. 选择版本或动作；
2. 预检兼容性、签名、发布者和权限；
3. 显示局部确认；
4. 执行事务；
5. 更新进度；
6. 成功后刷新目录和已安装插件侧栏；
7. 失败时保留可重试信息。

确认层规则：

- 打开后焦点进入主动作；
- `Tab` 仅在确认层内循环；
- `Esc` 在事务未开始时取消；
- 事务开始后关闭动作禁用或转换为“后台继续”；
- 危险动作使用明确动词，如“卸载插件”，不使用“确定”；
- 不允许重复提交；
- 完成后焦点返回触发确认的控件。

Long 当前已经在打开确认层时聚焦主动作，并支持 `Esc` 取消尚未执行的确认，应迁移并保持。

## 7. 插件设置模块

### 7.1 信息层级

建议顺序：

1. 插件图标、名称、版本、运行与更新状态；
2. 运行/打开主动作；
3. 插件专属设置；
4. 功能关键字与快捷键；
5. 权限、能力和调用记录；
6. 启停、重置、卸载等维护动作。

卸载和重置放在末尾危险区域，不与运行主按钮相邻。

### 7.2 状态保持

- 切换到其他模块后保留设置滚动位置；
- 未保存设置显示脏状态；
- 自动保存设置显示即时成功或失败反馈；
- 插件升级导致设置 Schema 变化时重新校验；
- 插件卸载时关闭设置模块；
- 插件运行失败只更新状态，不销毁设置模块。

### 7.3 键盘

- 初始焦点进入模块标题或首个设置项；
- `Ctrl+K` 进入作用域搜索；
- `Ctrl+Enter` 运行插件；
- `Esc` 先关闭弹层，再返回上一个模块；
- 危险操作必须通过可访问的确认层。

## 8. 插件运行模块与分离窗口

### 8.1 顶部信息

插件运行模块顶部显示：

- 真实插件图标；
- 插件名称；
- 当前功能关键字或调用来源；
- 运行状态；
- 更多菜单；
- 分离按钮；
- 关闭模块按钮。

不要显示“嵌入模式”这类面向实现的常驻标签。只有当用户需要理解行为差异时才提示当前状态。

### 8.2 五类退出相关动作

| 动作 | 视图 | 模块 | 运行时 |
|---|---|---|---|
| 返回 | 保留 | 切换到历史模块 | 保留 |
| 关闭模块 | 释放或缓存 | 关闭 | 按插件策略保留或停止 |
| 隐藏 Workspace | 保留 | 保留 | 保留 |
| 分离 | 所有权转移到独立窗口 | 标记为分离 | 保留同一实例 |
| 结束运行 | 关闭 | 关闭相关运行模块 | 停止并释放 |

宿主必须能解释每个动作的结果。更多菜单中“关闭页面”和“结束运行”必须是两个不同条目。

### 8.3 分离

`Ctrl+D`：

- 活动插件支持分离时，将同一会话迁入独立窗口；
- 不创建第二个插件运行时；
- 原模块条保留分离状态，可激活对应窗口；
- 再次请求嵌入时把同一视图迁回 Workspace；
- 输入、滚动、WebView2 页面与插件内状态保持。

分离窗口：

- 使用插件真实图标和 AppUserModelID；
- 标题为插件名称；
- 提供置顶、最小化、最大化和关闭；
- `Esc` 先交给插件内部临时层，再按插件策略退出或返回；
- 关闭窗口不应默认等于结束后台运行；
- 崩溃只影响当前插件会话。

本机实测表明插件锁定页可能消费或忽略 `Esc`。Long 应定义宿主与插件的按键优先级，不假设所有插件都遵循同一个页面级处理。

### 8.4 按键优先级

从高到低：

1. 系统级确认或安全对话框；
2. 插件内部模态层；
3. Workspace 局部弹层；
4. 插件运行模块；
5. Workspace 导航；
6. Launcher 全局入口。

插件处理 `Esc` 时必须返回是否已处理。未处理才由宿主执行返回或关闭模块。

## 9. `Esc` 统一层级

Workspace 中每次按下 `Esc` 只完成一层动作：

1. 取消菜单、提示或确认层；
2. 清空当前作用域搜索；
3. 从详情返回列表；
4. 从插件运行返回调用模块；
5. 关闭当前可关闭模块；
6. 根模块无历史时保持窗口，不直接退出宿主。

Launcher 中：

1. 有次级菜单时关闭菜单；
2. 否则隐藏 Launcher；
3. 恢复唤起前窗口焦点。

当前 Long 主窗口只区分工作流审查和嵌入插件，`Esc` 尚未经过统一导航状态机。

## 10. 焦点恢复契约

每个导航动作都必须记录返回焦点：

| 动作 | 返回焦点 |
|---|---|
| Launcher 执行后返回 | 原前台窗口 |
| Launcher 打开 Workspace | Workspace 活动模块首要控件 |
| 关闭模块 | 上一模块最近焦点 |
| 市场详情返回列表 | 原市场结果 |
| 关闭确认层 | 触发确认的按钮 |
| 插件分离 | 分离窗口插件内容 |
| 分离窗口返回嵌入 | Workspace 插件内容 |
| 卸载完成 | 插件目录相邻项或目录标题 |

不得统一把焦点粗暴设置到窗口根、页面顶部或搜索框。只有用户显式调用搜索时才强制聚焦搜索框。

## 11. 动画与反馈

### 11.1 动画

- Launcher 显示/隐藏：短淡入与轻位移；
- 模块切换：内容淡入，不推动整个 Shell；
- 侧栏选择：颜色和指示条变化，不改变行尺寸；
- 详情进入：紧凑布局可短距离横向过渡；
- 分离：不使用长时间缩放或飞行动画；
- 减少动画开启时全部降为即时状态变化。

### 11.2 状态反馈

- 搜索：增量结果和稳定状态；
- 安装：行内进度加全局可恢复状态；
- 设置保存：控件附近反馈；
- 插件崩溃：运行模块内错误状态和重启动作；
- 后台运行：侧栏状态点；
- 更新可用：非阻断标记；
- 市场离线：模块级提示，不发全局错误弹窗。

Toast 只用于跨模块完成事件，不代替当前模块内可操作的错误说明。

### 场景 A：从 Launcher 进入管理中心

Given 用户在任意前台应用唤起 Launcher

Then Launcher 隐藏
And Workspace 激活 management:root
And 输入上下文与原窗口引用被保存
And 不创建重复 Workspace 窗口

```text
Given management:root 已打开

```

### 场景 C：选择与运行插件

```text
Given 已安装插件目录可见
When 用户单击一个插件
Then 打开 plugin-settings:<id>

```

### 场景 D：分离与返回

```text
Given 插件运行模块处于活动状态
When 用户按 Ctrl+D
Then 同一 session 迁移到分离窗口
And 不创建第二个运行时或 WebView2
When 用户重新嵌入
Then 输入、滚动和插件状态保持
```

### 场景 E：逐层 `Esc`

```text
Given 市场详情上打开安装确认

Then 关闭市场模块并返回管理中心

```

### 场景 F：卸载活动插件

```text
Given 插件设置和运行模块均已打开
When 用户确认卸载
Then 插件事务成功后从侧栏移除
And 关闭该插件设置与运行模块
And 停止该插件运行时
And 焦点移到相邻插件或目录标题
And 其他模块与插件会话不受影响
```

## 15. 开发约束

- 不在新状态机完成前继续给 `ShowPage(string)` 添加页面；
- 不在 `MainWindow` 继续增加新的 `Visibility` 互斥分支；
- 不把插件运行状态保存在侧栏控件实例中；
- 不让每个模块自己监听全局 `Esc`；
- 不让页面自行决定是否创建第二个插件运行时；
- 不用坐标点击作为正式自动化验收；
- 不因参考 uTools 而复制其视觉、文案或商业入口；
