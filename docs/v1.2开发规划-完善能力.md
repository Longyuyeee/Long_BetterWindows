### 任务 #40-46: 创建示例插件库

#### #40: 时间戳工具 (timestamp)
**语言**: JavaScript  
**功能**: Alt+T 复制当前时间  
**能力**: clipboard, notification

```javascript
long.hotkey.register('Alt+T', async () => {
    const time = new Date().toLocaleString('zh-CN');
    await long.clipboard.setText(time);
    await long.notification.show(`⏰ ${time}`, 'success');
});
```
