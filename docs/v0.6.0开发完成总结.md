### ✅ 任务 #11: 权限管理可视化界面
**新增文件**:
- `CapabilityUsageTracker.cs` - API 调用统计服务
- `CapabilityMetadata.cs` - 权限元数据（图标、名称、描述、安全级别）
- `CapabilityDetailPanel.xaml/cs` - 权限详情面板

**功能**:
- 插件卡片添加 🔒 按钮
- 点击弹出权限详情对话框
- 显示每个权限的图标、名称、描述
- 安全等级标签（安全/中等/高危）
- API 调用统计（总次数、最后调用、最常用权限）
- WebView2 运行时自动记录 API 调用

**支持的权限**:
- 📋 剪贴板 (system.clipboard) - 安全
- 🗂️ 备用数据流 (fs.ads.access) - 中等
- ⌨️ 全局热键 (system.hotkey) - 安全
- 🔍 注册表读取 (system.registry.read) - 中等
- ⚠️ 注册表写入 (system.registry.write) - 高危
- 🌐 网络请求 (network.http) - 中等
- 📁 文件选择 (shell.selection) - 安全
- 🚀 执行命令 (shell.execute) - 中等
- 📸 截图 (system.screenshot) - 安全
- 🪟 窗口操作 (system.window) - 安全
- 💾 本地存储 (system.storage) - 安全
- 🖼️ 自定义窗口 (ui.window) - 安全
- 💬 通知 (ui.toast) - 安全

### ✅ 任务 #12: 插件依赖声明系统
**新增文件**:
- `PluginDependencyResolver.cs` - 依赖解析器

**manifest.json 新增字段**:
```json
{
  "dependencies": [
    {
      "plugin_id": "other-plugin",
      "min_version": "1.0.0"
    }
  ]
}
```

**功能**:
- 拓扑排序计算正确加载顺序
- 检测循环依赖
- 检查依赖是否满足
- 版本兼容性验证 (major.minor.patch)
- 查找依赖于指定插件的其他插件
- 卸载时检查被依赖情况

**核心方法**:
- `ResolveDependencies()` - 解析依赖，返回加载顺序
- `CheckDependencies()` - 检查依赖是否满足
- `FindDependents()` - 查找依赖于指定插件的其他插件
