## 🎯 核心任务 (6 个)

### 任务 #14: 插件市场 UI 面板 ⭐⭐⭐
**优先级**: P0（核心功能）

**目标**: 创建独立的插件市场面板，用户可以浏览、搜索、安装插件

**设计要点**:
- 顶部搜索栏 + 分类标签（全部/工具/效率/开发/娱乐）
- 插件卡片网格布局（3列）
- 每个卡片显示：
  - 插件图标（大）
  - 名称 + 版本
  - 作者 + 下载量
  - 简短描述（1-2 行）
  - 评分（⭐⭐⭐⭐⭐）
  - "安装"/"已安装"按钮
- 右侧插件详情面板（点击卡片展开）
  - 完整描述
  - 截图/预览
  - 权限列表
  - 依赖关系
  - 更新日志
  - 安装按钮

**技术实现**:
- 新增 `MarketPanel.xaml/cs`
- 新增 `MarketPluginCard.xaml` (UserControl)
- 新增 `PluginDetailView.xaml` (UserControl)

### 任务 #15: 插件市场本地 API ⭐⭐⭐
**优先级**: P0（核心功能）

**目标**: 实现本地 JSON 数据模拟插件市场 API

**API 接口**:
```csharp
// MarketApiService.cs
Task<List<MarketPlugin>> GetPluginsAsync(string? category = null);
Task<MarketPlugin?> GetPluginDetailAsync(string pluginId);
Task<List<MarketPlugin>> SearchPluginsAsync(string keyword);
Task<byte[]> DownloadPluginAsync(string pluginId, IProgress<double> progress);
Task<List<MarketPlugin>> GetFeaturedPluginsAsync();
Task<List<MarketPlugin>> GetUpdatesAsync(List<string> installedPluginIds);
```

**数据格式** (`market-data.json`):
```json
{
  "plugins": [
    {
      "id": "clipboard-manager",
      "name": "剪贴板管理器",
      "version": "1.2.0",
      "author": "LongDev",
      "category": "效率",
      "description": "增强剪贴板功能，支持历史记录、快速粘贴",
      "icon_url": "https://example.com/icon.png",
      "download_url": "https://example.com/plugin.lpak",
      "downloads": 1523,
      "rating": 4.8,
      "capabilities": ["system.clipboard", "system.hotkey", "system.storage"],
      "dependencies": [],
      "screenshots": ["url1", "url2"],
      "changelog": "v1.2.0: 新增快捷键支持\nv1.1.0: 修复内存泄漏",
      "size_bytes": 245760,
      "created_at": "2026-06-01",
      "updated_at": "2026-07-10"
    }
  ]
}
```

**实现**:
- 新增 `Services/MarketApiService.cs`
- 新增 `Contracts/MarketPlugin.cs`
- 新增 `market-data.json` (内置 10+ 示例插件)

### 任务 #16: 插件一键安装功能 ⭐⭐⭐
**优先级**: P0（核心功能）

**目标**: 从市场直接下载并安装插件

**功能**:
- 点击"安装"按钮开始下载
- 显示下载进度条（百分比 + 速度）
- 下载完成后自动调用 `LpakInstallerService` 安装
- 安装成功后：
  - Toast 提示 "安装成功"
  - 卡片按钮变为"已安装"
  - 插件列表自动刷新
- 安装失败时显示错误信息

**交互优化**:
- 下载中禁用按钮，显示进度
- 支持取消下载
- 已安装的插件显示"打开"按钮

**实现**:
- 扩展 `MarketApiService` 添加下载方法
- 在 `MarketPanel` 中集成安装流程
- 复用 `LpakInstallerService`

### 任务 #17: 插件自动更新检测 ⭐⭐
**优先级**: P1（重要功能）

**目标**: 检测已安装插件的新版本，提示用户更新

**功能**:
- 启动时自动检查更新（后台）
- 对比本地版本和市场版本
- 有更新时在插件卡片显示 "🔄 可更新" 徽章
- 点击徽章弹出更新对话框：
  - 显示新版本号
  - 显示更新日志
  - "立即更新"按钮
- 更新流程 = 下载 + 卸载旧版 + 安装新版

**技术实现**:
- 新增 `UpdateCheckerService.cs`
- 定期检查（每 24 小时 / 手动触发）
- 版本比较使用语义化版本

---

### 任务 #18: 性能监控面板 ⭐⭐
**优先级**: P1（重要功能）

**目标**: 监控插件的资源使用情况

**监控指标**:
- CPU 使用率（%）
- 内存占用（MB）
- API 调用频率（次/秒）
- 线程数
- 错误/异常次数

**UI 设计**:
- 在插件卡片右上角显示性能指示器（绿色/黄色/红色圆点）
- 点击性能指示器展开详情面板：
  - 实时图表（折线图）
  - 性能指标列表
  - 警告信息（高内存/高频调用）
- 在系统设置中添加"性能"标签页
  - 显示所有插件的资源使用排行
  - 设置性能阈值（警告/错误）

**技术实现**:
- 新增 `PerformanceMonitor.cs`
- 使用 `Process.GetCurrentProcess()` 获取资源数据
- 每 5 秒采样一次
- 使用 `LiveCharts` 库绘制图表

### 任务 #19: UI 美化最终优化 ⭐⭐⭐
**优先级**: P0（核心体验）

**目标**: 完善所有 UI 细节，达到"扁平、华丽、优雅、动效平滑"的最终状态

**优化项**:

#### 1. Acrylic 毛玻璃效果
- 主窗口背景使用 `AcrylicBrush`
- 插件卡片悬停时背景模糊
- 对话框/面板半透明背景

#### 2. 渐变优化
- 插件卡片顶部状态条使用渐变
- 按钮悬停时背景渐变
- 市场卡片分类标签渐变背景

#### 3. 阴影增强
- 所有浮动元素添加 `DropShadowEffect`
- 阴影深度根据元素层级变化
- 悬停时阴影加深

#### 4. 动画完善
- 所有页面切换统一使用淡入淡出
- 列表项加载时逐个滑入
- 按钮点击时缩放反馈
- 对话框弹出时从中心放大
- Toast 通知从右上角滑入

#### 5. 字体优化
- 使用 Segoe UI Variable / 微软雅黑
- 标题使用 SemiBold
- 正文使用 Regular
- 代码使用 Consolas / Cascadia Code

#### 6. 颜色系统
- 定义完整的颜色调色板
- 深色/浅色主题切换
- 强调色/警告色/成功色统一

**技术实现**:
- 扩展 `App.xaml` 资源字典
- 创建 `Styles/ModernStyles.xaml`
- 创建 `Animations/AnimationExtensions.cs`
