### 任务 #31: 插件详情展开视图 📖 (P0)
**目标**: 提供更丰富的插件信息展示

**实现内容**:
- 插件卡片右上角添加"详情"按钮（ℹ️）
- 点击后卡片展开动画：120px → 400px
- 详情区域使用 TabControl 分页：
  - **概览** Tab: 完整描述、作者、版本、更新日期
  - **权限** Tab: 所有 capabilities + API 调用统计
  - **依赖** Tab: 依赖关系图
  - **日志** Tab: 最近 50 条 API 调用记录
- 展开时其他卡片下移（平滑动画）
- 再次点击或点击外部收起

**交互流程**:
```
普通卡片 (120px)
    ↓ 点击详情
展开卡片 (400px)
  ┌─────────────────┐
  │ 基本信息        │
  ├─────────────────┤
  │ [概览][权限][依赖][日志] │
  │                 │
  │  Tab 内容区域   │
  │                 │
  └─────────────────┘
```
