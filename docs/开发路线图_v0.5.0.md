```markdown
### 能力名称（如：HotKeyService）

**能力 ID：** `system.hotkey`
**接口：** `IHotKeyService`

#### C# API

\`\`\`csharp
Task<bool> RegisterAsync(string hotkey, Action callback);
Task<bool> UnregisterAsync(string hotkey);
\`\`\`

#### JavaScript API

\`\`\`javascript
await long.hotkey.register("Ctrl+Shift+X", () => { /* ... */ });
await long.hotkey.unregister("Ctrl+Shift+X");
\`\`\`

#### 参数说明
- `hotkey`: 热键组合（格式：Modifier+Key）
- `callback`: 热键触发时的回调函数

#### 返回值
- `true`: 注册成功
- `false`: 注册失败（冲突或格式错误）

#### 错误代码
- `HOTKEY_CONFLICT`: 热键已被占用
- `INVALID_FORMAT`: 热键格式错误

#### 完整示例

**C# 插件：**
\`\`\`csharp
public async Task<bool> StartAsync()
{

private void OnHotkey()
{
    Log.Information("热键触发");
}
\`\`\`

**Web 插件：**
\`\`\`javascript
async function init() {
    await long.hotkey.register("Alt+X", () => {
        long.app.showToast("热键触发");
    });
}
\`\`\`
```

```csharp
public async Task<PackResult> PackPluginAsync(string pluginDir)
{
    var scriptPath = Path.Combine(AppDomain.CurrentDomain.BaseDirectory, 
        "pack-plugin.ps1");
    
    var process = new Process
    {
        StartInfo = new ProcessStartInfo
        {
            FileName = "powershell.exe",
            Arguments = $"-File \"{scriptPath}\" -PluginDir \"{pluginDir}\"",
            RedirectStandardOutput = true,
            UseShellExecute = false
        }
    };
    
    process.Start();
    var output = await process.StandardOutput.ReadToEndAsync();
    await process.WaitForExitAsync();
    
    return new PackResult
    {
        Success = process.ExitCode == 0,
        OutputPath = ExtractLpakPath(output),
        Message = output
    };
}
```

**任务 3：实时日志查看器**

架构设计：

1. **日志收集器（LogCollectorSink.cs）**
```csharp
public class LogCollectorSink : ILogEventSink
{
    private static readonly ConcurrentDictionary<string, Queue<LogEntry>> 
        _pluginLogs = new();
    
    public void Emit(LogEvent logEvent)
    {
        var pluginId = logEvent.Properties.GetValueOrDefault("PluginId")?.ToString();
        if (string.IsNullOrEmpty(pluginId)) return;
        
        var entry = new LogEntry
        {
            Timestamp = logEvent.Timestamp,
            Level = logEvent.Level,
            Message = logEvent.RenderMessage()
        };
        
        _pluginLogs.GetOrAdd(pluginId, _ => new Queue<LogEntry>())
                   .Enqueue(entry);
    }
    
    public static LogEntry[] GetLogs(string pluginId, int count = 100)
    {
        return _pluginLogs.TryGetValue(pluginId, out var queue)
            ? queue.TakeLast(count).ToArray()
            : Array.Empty<LogEntry>();
    }
}
```

目标：保存代码自动重载插件

- 检测到修改后重新加载

改进方案：

1. **调试模式开关**
```csharp
public class PluginRegistry
{
    public bool IsDebugMode { get; set; }
    
    public async Task EnableDebugModeAsync(string pluginId)
    {
        var entry = _plugins[pluginId];
        entry.IsDebugMode = true;
        
        // 监控源代码目录而非输出目录
        var srcDir = Path.Combine(entry.Directory, "..", "..", "src");
        _fileWatcher.Watch(srcDir, "*.cs", async () => {
            await RecompileAndReloadAsync(pluginId);
        });
    }
}
```

2. **自动重编译**
```csharp
private async Task RecompileAndReloadAsync(string pluginId)
{
    var entry = _plugins[pluginId];
    
    // 1. 执行 dotnet build
    var buildResult = await ExecuteBuildAsync(entry.ProjectPath);
    if (!buildResult.Success)
    {
        NotifyBuildFailed(buildResult.Errors);
        return;
    }
    
    // 2. 保存插件状态
    var state = await entry.Instance.SaveStateAsync();
    
    // 3. 卸载插件
    await entry.Instance.StopAsync();
    entry.Context.Unload();
    
    // 4. 重新加载
    var newInstance = await _loader.LoadAsync(entry.Directory, entry.Manifest);
    await newInstance.InitializeAsync(_hostApi);
    await newInstance.RestoreStateAsync(state);
    await newInstance.StartAsync();
    
    NotifyReloadSuccess(pluginId);
}
```

3. **状态保持接口（可选）**
```csharp

{
    Task<PluginState> SaveStateAsync();
    Task RestoreStateAsync(PluginState state);
```

**任务 5：新能力 - Dialog 对话框**

目标：实现文件/文件夹选择、颜色选择器等常用对话框

接口设计：

```csharp
namespace LongBetterWindows.Host.Capabilities
{
    public interface IDialogService
    {
        /// <summary>打开文件对话框</summary>
        Task<string?> OpenFileAsync(FileDialogOptions options);
        
        /// <summary>保存文件对话框</summary>
        Task<string?> SaveFileAsync(FileDialogOptions options);
        
        /// <summary>选择文件夹对话框</summary>
        Task<string?> SelectFolderAsync();
        
        /// <summary>颜色选择器</summary>
        Task<Color?> PickColorAsync(Color? initialColor = null);
        
        /// <summary>确认对话框</summary>
        Task<bool> ConfirmAsync(string title, string message);
        
        /// <summary>输入对话框</summary>
        Task<string?> PromptAsync(string title, string placeholder = "");
    }
    
    public class FileDialogOptions
    {
        public string Title { get; set; } = "选择文件";
        public string Filter { get; set; } = "所有文件 (*.*)|*.*";
        public string InitialDirectory { get; set; } = "";
        public bool Multiselect { get; set; } = false;
    }
}
```

实现要点：

```csharp
public class DialogService : IDialogService
{
    public async Task<string?> OpenFileAsync(FileDialogOptions options)
    {
        return await Application.Current.Dispatcher.InvokeAsync(() =>
        {
            var dialog = new Microsoft.Win32.OpenFileDialog
            {
                Title = options.Title,
                Filter = options.Filter,
                InitialDirectory = options.InitialDirectory,
                Multiselect = options.Multiselect
            };
            
            return dialog.ShowDialog() == true ? dialog.FileName : null;
        });
    }
    
    public async Task<string?> SelectFolderAsync()
    {
        return await Application.Current.Dispatcher.InvokeAsync(() =>
        {
            using var dialog = new System.Windows.Forms.FolderBrowserDialog();
            return dialog.ShowDialog() == System.Windows.Forms.DialogResult.OK
                ? dialog.SelectedPath
                : null;
        });
    }
    
    public async Task<bool> ConfirmAsync(string title, string message)
    {
        return await Application.Current.Dispatcher.InvokeAsync(() =>
        {
            var result = MessageBox.Show(message, title, 
                MessageBoxButton.YesNo, MessageBoxImage.Question);
            return result == MessageBoxResult.Yes;
        });
    }
}
```
