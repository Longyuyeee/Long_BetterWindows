## 执行原则

- 严格按“协议 → 设计系统 → 核心界面 → 插件迁移 → 质量验收”的顺序推进。
- 每一阶段必须有编译、自动化测试和明确验收结果。
- 未通过阶段验收前，不将视觉草案混入正式实现。
- uTools 仅作为交互逻辑和产品结构参考；视觉表现采用 Long 自有的优雅、华丽、扁平、动效化设计语言。
