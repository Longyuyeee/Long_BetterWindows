## 📋 任务清单

### 任务 #34: 扩展原子能力 API (P0)

**目标**: 从 13 种能力扩展到 19 种能力

**新增 6 种能力**:

#### 1. process - 进程管理
```csharp
interface IProcessService
{
    // 启动进程
    Task<HostApiResponse<int>> StartAsync(string path, string? args = null);
    
    // 结束进程
    Task<HostApiResponse> KillAsync(int pid);
    
    // 获取进程列表
    Task<HostApiResponse<List<ProcessInfo>>> GetListAsync();
    
    // 检查进程是否运行
    Task<HostApiResponse<bool>> IsRunningAsync(string processName);
}
```

**使用场景**: 启动应用、管理后台进程、检查程序状态

---

#### 2. audio - 音频控制
```csharp
interface IAudioService
{
    // 设置音量 (0-100)
    Task<HostApiResponse> SetVolumeAsync(int volume);
    
    // 获取当前音量
    Task<HostApiResponse<int>> GetVolumeAsync();
    
    // 静音/取消静音
    Task<HostApiResponse> SetMuteAsync(bool mute);
    
    // 播放系统声音
    Task<HostApiResponse> PlaySoundAsync(string soundType);
}
```

**使用场景**: 快捷键控制音量、会议一键静音、提示音播放

---

#### 3. monitor - 多显示器管理
```csharp
interface IMonitorService
{
    // 获取显示器列表
    Task<HostApiResponse<List<MonitorInfo>>> GetListAsync();
    
    // 获取主显示器
    Task<HostApiResponse<MonitorInfo>> GetPrimaryAsync();
    
    // 移动窗口到指定显示器
    Task<HostApiResponse> MoveWindowToMonitorAsync(IntPtr hwnd, int monitorIndex);
    
    // 获取鼠标所在显示器
    Task<HostApiResponse<int>> GetMouseMonitorAsync();
}
```

**使用场景**: 窗口管理、多屏工作流、投屏辅助

---

#### 4. power - 电源管理

interface IPowerService

**使用场景**: 电池监控、性能模式切换、下载时防止休眠
