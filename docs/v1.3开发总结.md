# Long窗口 v1.3 开发总结

## 新增底层能力（3项）

### 1. system.clipboard.monitor — 剪贴板变更监听
**文件**: `IClipboardService.cs`, `ClipboardService.cs`

**新增 API**:
- `StartMonitoringAsync()` - 开始监听剪贴板变化
- `StopMonitoringAsync()` - 停止监听
- `ClipboardChanged` 事件 - 剪贴板内容变化时触发
- `IsMonitoring` 属性 - 监听状态

**实现机制**: Windows Clipboard Chain (SetClipboardViewer + WM_DRAWCLIPBOARD)

---

### 2. network.ports — 端口与进程映射
**文件**: `INetworkPortService.cs`, `NetworkPortService.cs`

**新增 API**:
- `GetTcpConnectionsAsync()` - 获取所有 TCP 连接
- `GetTcpListenersAsync()` - 获取监听中的 TCP 端口
- `GetUdpEndpointsAsync()` - 获取 UDP 端点
- `FindPortOwnerAsync(port, protocol)` - 查找占用指定端口的进程
- `IsPortInUseAsync(port, protocol)` - 检查端口占用
- `GetPortSummaryAsync()` - 端口占用汇总统计

**实现机制**: 
- IPGlobalProperties API 获取端口信息
- GetExtendedTcpTable/GetExtendedUdpTable Win32 API 实现端口-进程映射

---

### 3. system.performance — 系统性能监控
**文件**: `IPerformanceService.cs`, `PerformanceService.cs`

**新增 API**:
- `GetCpuUsageAsync()` - 获取 CPU 使用率
- `GetMemoryInfoAsync()` - 获取内存信息（总量/已用/可用/占比）
- `GetDiskInfoAsync()` - 获取磁盘使用情况
- `GetSystemInfoAsync()` - 获取系统信息（OS/CPU/内存/运行时间）
- `GetTopProcessesByCpuAsync(count)` - CPU 占用 Top N 进程
- `GetTopProcessesByMemoryAsync(count)` - 内存占用 Top N 进程

**实现机制**:
- PerformanceCounter 获取 CPU 使用率
- GlobalMemoryStatusEx Win32 API 获取内存信息
- DriveInfo 获取磁盘信息
- Process API 获取进程资源占用

---

## 新增插件（4个）

### 1. DevToolkit — 开发者工具箱 ✅
**ID**: `com.long.devtoolkit`  
**运行时**: WebView (HTML/JS)  
**能力**: `system.clipboard`

**功能**:
- Base64 编码/解码
- MD5/SHA-1/SHA-256 哈希计算
- UUID 生成（v4/短UUID/时间戳ID）
- 时间戳 ↔ 日期转换
- 进制转换（十进制/十六进制/八进制/二进制）
- URL 编码/解码
- Unicode 转换

**特色**: 输入即识别，自动复制结果到剪贴板

---

### 2. ClipboardHistory — 剪贴板历史 ✅
**ID**: `com.long.clipboardhistory`  
**运行时**: WebView (HTML/JS)  
**能力**: `system.clipboard`, `system.clipboard.monitor`, `storage.local`, `system.hotkey`

**功能**:
- 自动记录剪贴板历史（最多 500 条）
- 按关键词/时间/类型搜索
- 一键复制历史内容回剪贴板
- 支持文本/图片/文件类型识别
- 热键 `Ctrl+Shift+V` 快速打开

**特色**: 轮询实现（每秒检测），本地持久化存储

---

### 3. PortManager — 端口管理器 ✅
**ID**: `com.long.portmanager`  
**运行时**: WebView (HTML/JS)  
**能力**: `network.ports`, `system.process`, `system.clipboard`

**功能**:
- 端口扫描（TCP 监听/TCP 连接/UDP 端点）
- 进程识别（显示占用端口的进程名、PID、路径）
- 占用分析（按端口号搜索、查找占用进程）
- 安全释放（终止占用端口的进程，带确认提示）
- 实时刷新、统计汇总

**特色**: 
- 三种视图切换（监听/连接/UDP）
- 端口查找模态框
- 进程信息详细展示

---

### 4. HardwareMonitor — 硬件监控 ✅
**ID**: `com.long.hardwaremonitor`  
**运行时**: WebView (HTML/JS)  
**能力**: `system.performance`, `system.process`

**功能**:
- 实时监控 CPU/内存使用率（带警告阈值）
- 系统信息展示（OS/机器名/处理器/内存/运行时间）
- 磁盘使用情况（多盘符支持）
- 进程资源占用 Top 10（按内存排序）
- 自动刷新（默认 2 秒间隔）

**特色**:
- 卡片式 UI，进度条可视化
- 超过阈值自动标红警告
- 字节格式化显示（B/KB/MB/GB）

## 技术亮点

1. **Win32 API 集成** - 使用 P/Invoke 调用底层 Windows API 实现深度系统集成
2. **权限沙盒** - 所有新能力遵循 manifest capabilities 声明机制
3. **WebView 插件优势** - 4 个插件全部使用 HTML/JS，开发速度快，UI 灵活
4. **实时监控** - 剪贴板历史轮询、硬件监控定时刷新，提供流畅的用户体验
5. **可视化设计** - 进度条、卡片、表格等 UI 元素，符合 Apple 风格设计语言
