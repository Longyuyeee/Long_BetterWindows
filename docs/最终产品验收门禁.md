# 最终产品验收门禁

最终外部发布决策现在强制要求 `approved_final_product_acceptance` 输入，避免只完成安装、DPI、辅助功能
和 Marketplace 演练后就错误地宣告整个产品可发布。

该摘要必须绑定同一个 40 位源码提交，并满足：

- 插件矩阵为 25 个插件、42 条命令、25 份有效人工批准回执且 `release_eligible=true`；
- `taskbar-visual-grouping` 已在 Explorer 中实际观察并批准；
- `native-performance` 已完成管理员 WPR/WPA 分析并批准；
- `lpwp-long-grid-e2e` 已在 Long Grid 工程完成真实握手、目录、命令/取消与 `plugin.open`；
- `lpwp-widget-desktop` 已完成参考 Widget 安装、双实例、移动缩放、重启恢复、暂停与帮助检查；
- `lpwp-signed-reference` 使用用户认可的 Marketplace 发布者身份完成签名与独立指纹复核。

五类批准和插件矩阵都必须以 `<摘要名>.sources/` 下的可移植 JSON 随摘要交付，摘要记录每份来源的
SHA-256；最终决策会重新读取来源内容，核对分类、提交、批准状态、审核人和精确 ID 集合。仅手工把摘要
中的 `passed` 改成 `true` 不会通过。

## 生成五类批准回执

所有原始截图、录像、ETL 和机器报告保留在 `artifacts/quality/`。确认每项真实通过后，从干净跟踪提交运行：

```powershell
.\approve-final-validation-evidence.ps1 `
  -ValidationId taskbar-visual-grouping `
  -ExpectedSourceCommit "<冻结候选的完整 40 位提交>" `
  -Reviewer "<审核人>" -Notes "<实际观察结论>" `
  -EvidenceFiles "artifacts/quality/<任务栏截图或录像>" `
  -ConfirmPassed
```

`ValidationId` 依次完成五项：`taskbar-visual-grouping`、`native-performance`、
`lpwp-long-grid-e2e`、`lpwp-widget-desktop`、`lpwp-signed-reference`。

- WPR 批准必须把 `native-performance-evidence.json` 放入 `EvidenceFiles`，脚本先运行现有完整性验证；
- Long Grid 必须提供 `classification=lpwp_long_grid_e2e`、两个完整源码提交、协议名、通过状态及六个已验证方法；
- 签名参考包必须提供 `classification=lpwp_signed_reference` 报告，并额外传入独立记录的
  `-ExpectedPublisherKeyId` 与 `-ExpectedPublicKeyFingerprint`；
- 任务栏和 Widget 属于主观/交互验收，只能在审核人实际查看原始截图或录像后使用 `-ConfirmPassed`。

脚本在 `docs/final-validation-approvals/` 生成不含原始内容的哈希回执。每生成一份回执就单独提交；后续批准仍传入
同一个冻结候选提交。候选之后只允许新增或更新两个批准目录中的 JSON，任何产品、脚本或文档变化都会要求重新冻结
候选并重新验收。保留冻结候选实际受测的 Release EXE；不要在提交回执后用新 `HEAD` 重建并替换它。若在另一工作树
或电脑汇总，通过 `-SubjectExecutable` 指向该候选 EXE。五份回执和 25 份插件回执完成后，从干净提交生成可移植摘要：

```powershell
.\verify-final-product-acceptance.ps1 `
  -ExpectedSourceCommit "<冻结候选的完整 40 位提交>" `
  -OutputPath "artifacts/quality/final-product/product-acceptance.json"
```

汇总器会重新运行插件矩阵并要求 `release_eligible=true`，要求五份精确、已提交、绑定当前宿主哈希的回执，
再生成摘要及同名 `.sources/` 目录。把这两者一起交给 `verify-external-release-gate.ps1` 的
`-ProductAcceptanceGatePath`。当前真实证据尚未完成，因此该汇总器会按设计拒绝生成通过摘要。
