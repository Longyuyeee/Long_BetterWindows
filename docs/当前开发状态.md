# Long窗口当前开发状态

> 最后更新：2026-07-20
> 唯一开发主线：`master`
> 当前版本：`v1.9.0`

## 当前基线

- .NET 8 WPF 宿主，支持 DLL、C# Script 和 WebView2 三种插件运行时。
- 27 个宿主能力接口，v1.8 的壁纸、亮度、网络监控等能力全部保留。
- 25 个内置插件，发布项目必须复制 25 个插件目录和 25 个 Manifest。
- Long Design System、统一命令中心、上下文搜索、超级面板和鼠标手势已进入主线。
- 可信插件市场支持签名校验、安装、升级、降级、卸载、中断恢复、离线缓存和并发控制。
- 市场发布工具支持目录生成、部署、验证和回滚。
- 合并后 Debug/Release 构建均为 0 警告、0 错误，自动化测试 215 / 215 通过。
- `win-x64` 自包含与框架依赖发布包均已通过宿主冒烟，包含 25 个插件目录、25 个 Manifest 和 25 个唯一插件 ID，并生成双包 SHA-256。
- 25 插件连续 5 次空闲内存采样通过：中位数 165.6 MB，最大值 181.4 MB，低于 200 MB 门槛。

## 发布状态

代码侧功能已进入 v1.9 发布收口阶段。正式发布仍需完成：

1. 真实 Registry/CDN、公钥和发布凭据的受控环境演练。
2. Windows 代码签名、干净用户环境以及物理 DPI/可访问性人工签核。
