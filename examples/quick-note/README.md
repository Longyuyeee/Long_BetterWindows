# 快速笔记

快捷键弹出笔记窗口，支持多条笔记管理。

## 功能

- `Ctrl+Shift+N` - 打开笔记窗口
- 新建、编辑、删除笔记
- 自动保存到本地存储
- 显示创建时间

## 使用方法

1. 将 `quick-note.csx` 拖入 Long_BetterWindows
2. 等待自动加载
3. 按 `Ctrl+Shift+N` 打开笔记窗口

## 能力声明

- `system.storage` - 持久化笔记数据
- `system.window` - 创建自定义窗口
- `system.hotkey` - 全局热键

## 特性

- 暗色主题界面
- 响应式布局
- 实时保存
- 时间戳显示

1. C# 脚本中使用类和方法
